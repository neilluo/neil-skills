# QoderWork 快速开始

> 下载 → 登录 → 认识界面 → 跑通第一个任务，5 分钟体验完整流程。

## 概述

QoderWork 是桌面端智能工作助手，用自然语言描述需求即可交付产物文件。本指南带你完成首次体验。

## 步骤

### 1. 下载安装
- 访问 qoder.com/zh/qoderwork
- macOS 14+（Apple Silicon / Intel）或 Windows 10+（64位）
- 磁盘空间 ≥ 500 MB

### 2. 登录
- 与 Qoder Desktop / CLI 共用账户，Credits 余额共享
- 历史任务保存本地，不跨设备同步

### 3. 认识界面
- 左侧导航：新任务 / 扩展 / 定时任务 / IM 频道 / 任务历史 / 设置
- 右侧工作区：对话 + 任务监控 + 产物

### 4. 第一个任务
- 保持默认「通用工作台 + 标准模型」
- 面向结果描述需求 → 回车发送
- 执行流程：澄清(可选) → 任务监控 → 收取产物

## 三个核心概念
- **澄清**：任务前的简短确认
- **任务监控**：实时展示计划/工具/产物
- **产物**：本地文件形式的任务输出
