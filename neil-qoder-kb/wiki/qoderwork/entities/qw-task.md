# QoderWork Task（任务与产物）

> QoderWork 的核心交互单元：自然语言描述目标 → AI 规划执行 → 交付产物文件。

## 概述

QoderWork 以「任务」为核心交互单元。用户描述目标，AI 自主规划与执行，最终交付可下载的本地产物文件。任务全程透明可控：澄清→监控→收取→迭代。

## 任务创建四步

1. **描述任务**：面向结果描述"要拿到什么"
2. **选工作台**：通用 / 设计 / 幻灯片（Beta）/ 写作（Beta）
3. **选模型**：标准 / 旗舰 / 指定模型
4. **选工作目录（可选）**：绑定本地文件夹

## 上下文丰富方式

| 入口 | 说明 |
|------|------|
| `+` 菜单 | 专家套件 / 技能 / 连接器 / 添加文件 |
| `@` 引用 | 专家套件 / 历史任务 / 定时任务 |
| `/` 调用 | 技能与指令 |

## 执行过程

- **左侧对话流**：模型逐步输出思考、工具调用、结论
- **右侧任务监控**：待办计划 + 产物 + Skills & MCP

## 产物（Artifacts）

任务输出的具体文件（表格/幻灯片/报告/代码等），是真实的本地文件，直接创建并保存在电脑上。

## 追加与迭代

任务执行中或结束后均可追加指令。QoderWork 保留完整上下文，支持增量修改。
