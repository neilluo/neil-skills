# QoderWork vs QoderWake

> 两款桌面端 AI 产品的定位对比：个人工作助手 vs 数字员工团队。

## 概述

QoderWork 和 QoderWake 都是本地部署的桌面端产品，但面向不同场景和用户群体。

## 对比

| 维度 | QoderWork | QoderWake |
|------|-----------|-----------|
| **定位** | 桌面端智能工作助手 | 本机部署数字员工团队 |
| **目标用户** | 任何知识工作者 | 开发者/技术团队 |
| **核心场景** | 文件处理/数据分析/文档创作/信息整理 | 代码开发/自动化任务/技术调研 |
| **任务模型** | 单任务对话（澄清→执行→产物） | 三种任务类型（对话/自动/群组） |
| **记忆系统** | 意识系统（SOUL.md + AGENTS.md + USER.md + MEMORY.md） | Waker 记忆（自动沉淀/手动/系统整理） |
| **扩展机制** | 技能 + 连接器 + 专家套件 | 技能 + 连接器 + 项目 |
| **协同模式** | 个人为主，IM 频道分发 | Leader + 成员群组协作 |
| **桌面操控** | Computer Use（截屏+鼠标键盘） | 不直接操控桌面 |
| **定时调度** | 本地定时任务（电脑需唤醒） | 自动触发（定时/事件/API，本机调度） |
| **IM 集成** | 钉钉/飞书/微信/企业微信 | 不直接集成 IM |

## 选型建议

- **选 QoderWork**：日常文件整理、文档创作、数据分析、跨应用自动化、非编程工作
- **选 QoderWake**：开发相关任务、需要多角色协作、偏重代码生成与 bug 修复
