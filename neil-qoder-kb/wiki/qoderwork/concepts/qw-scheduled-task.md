# Scheduled Task（定时任务）

> 让 QoderWork 从「你问它才动」变成「到点自己干」——本地调度的自动化任务执行。

## 概述

定时任务在预定时间自动新建对话任务并按 Prompt 执行。执行时拥有与手动对话完全一样的能力（MCP/连接器/技能/读写文件）。由本地桌面客户端调度，以系统时区为准。

## 工作原理
到预定时间 → 自动新建对话任务 → 按 Prompt 执行 → 结果保存在该对话中

**限制**：电脑睡眠/关机时无法触发（可开启"保持系统唤醒"）。

## 创建方式
1. **对话中创建（推荐）**：用自然语言描述"什么时间做什么事"
2. **界面面板创建**：定时任务页面 → + 新建 → 表单配置

## 调度类型

| 类型 | 适用场景 |
|------|----------|
| 不重复 | 会议资料准备、截止日检查 |
| 间隔 | 价格监控、数据采集 |
| 每小时 | 监控告警、状态同步 |
| 每天 | 每日早报、数据报表 |
| 每周 | 周报草稿、竞品追踪 |
| 每月 | 月度分析、账单汇总 |

## 与 IM 频道配合
定时任务结果可配置推送到指定 IM 会话（如"每天早上 9 点生成日报发到钉钉群"）。
