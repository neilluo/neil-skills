# Computer Use（电脑操控）

> 让 QoderWork 直接"看到"和"操控"桌面屏幕——在图形界面中完成没有 API 的应用操作。

## 概述

Computer Use 让 QoderWork 通过截屏感知界面、通过鼠标键盘操控应用。适用于没有命令行或 API 的桌面应用、跨应用工作流、GUI 验证等场景。

## 核心能力
- **屏幕感知**：截屏读取窗口内容，理解布局和 UI 状态
- **鼠标与键盘控制**：点击/双击/拖拽/输入/快捷键，像素级精度
- **后台自主执行**：不抢占前台焦点
- **跨应用流程**：多应用切换，根据实时反馈动态调整

## 系统要求
- macOS 14+
- 辅助功能权限 + 屏幕录制权限

## 开启方式
扩展 → 连接器 → 计算机控制 → 开启

## 执行策略

| 策略 | 说明 |
|------|------|
| 每次询问（默认） | 每次操控前征求确认 |
| 自动执行 | 直接执行 |
| 禁用 | 完全关闭 |

## 操作透明度
截屏 → 操作描述 → 实际操作 → 结果确认（再次截屏）

## 限制与注意
- 无法完成 CAPTCHA / 二步验证
- 比纯文本操作慢（需要截屏分析）
- 授予权限 = 授予操控权限，效果等同本人操作
- 部分操作不可撤销（发消息/删除文件）
