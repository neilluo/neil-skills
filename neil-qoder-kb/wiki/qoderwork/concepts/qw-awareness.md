# Awareness（意识系统）

> QoderWork 的跨会话记忆与个性化系统——持续记录偏好和工作习惯，让每次新对话带着完整上下文。

## 概述

意识系统由两个主开关控制：意识模式（按定制风格工作+跨会话记忆）和自动记忆（自动维护画像与记忆+定期反思）。所有意识文件存储在 `~/qoderwork/awareness/main`。

## 意识文件体系

| 文件 | 作用 | 维护者 |
|------|------|--------|
| SOUL.md | 协作风格：沟通和协作方式 | 用户定义 |
| AGENTS.md | 工作手册：工作规范和行为准则 | 用户定义 |
| USER.md | 用户画像：基本信息、偏好、习惯 | 自动维护 |
| MEMORY.md | 长期记忆：跨会话持久知识和结论 | 自动维护 |
| memory/ | 短期记忆：按天记录的对话摘要 | 自动维护 |

## 进化动态
- 记忆趋势图（天/周/月视角）
- 今日统计：审查次数、新增记忆、技能更新、反思次数
- 近期动态：时间倒序列出最新写入与反思记录

## 危险操作（不可恢复）
- 重置协作风格 / 重置工作手册 / 清空记忆

## 与 CLI 记忆系统的对比
- QoderWork：面向非编程场景，SOUL.md + AGENTS.md + USER.md + MEMORY.md
- QoderCLI：面向开发场景，AGENTS.md + 自动记忆双轨
