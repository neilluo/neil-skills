# Desktop 快速开始

> 下载 → 登录 → 打开项目 → 体验 NEXT/行间会话/Ask/Agent/Quest，5 分钟上手 Qoder Desktop。

## 概述

本指南带你以个人用户身份完成 Qoder Desktop 的首次体验，覆盖 NEXT 代码建议、行间会话、右侧会话（Ask/Agent）和 Quest 自主委派四大核心交互入口。

## 步骤

### 1. 下载并安装
- 从 https://qoder.com/download 下载
- 双击安装并启动 Qoder IDE

### 2. 登录
- IDE 右上角用户图标 → 登录（⌘⇧, / Ctrl+Shift+,）
- 支持注册、Google、GitHub 账号

### 3. 打开项目
- 本地项目：⌘O / Ctrl+O
- 克隆：Clone repo → URL 或 GitHub

### 4. 四大入口速览

| 入口 | 快捷键 | 定位 |
|------|--------|------|
| NEXT | ⌥P 唤出 / Tab 采纳 | 实时代码预测 |
| 行间会话 | ⌘I / Ctrl+I | 代码上下文中生成代码 |
| Ask/Agent | ⌘L / Ctrl+L | 问答或自主编码 |
| Quest | Editor 右上角打开 | 自主委派长程任务 |
