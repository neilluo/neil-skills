# Quest（自主委派工作台）

> 面向 Agent-first 的独立视窗，支持多任务并行调度与多智能体专家协同，实现"定义目标，审查结果"的工作范式。

## 概述

Quest 是 Qoder Desktop 的第二主视图，专为将长程、多步任务交给 Agent 持续执行而设计。三栏布局（任务管理 + 会话 + 功能区）提供完整的任务看板、进度追踪与产物审查能力。

## 两种子模式

| 模式 | 定位 | 适用场景 |
|------|------|----------|
| **Agent 模式** | 单智能体自主执行 | 端到端交付单一任务 |
| **Experts 模式** | 多智能体协同并行 | 全栈开发、技术调研、疑难修复 |

模式在任务创建时确定，后续不可切换。

## 核心能力

- **多任务并行调度**：多项目、多任务统一界面统筹
- **多智能体专家协同**：从 Coding 到交付端到端执行
- **知识与记忆沉淀**：持续沉淀项目知识、任务经验
- **自定义专家团队**：灵活定义角色、流程与能力边界

## 三栏布局

| 区域 | 内容 |
|------|------|
| 左侧：任务管理 | 工作区组织、任务状态（Running/Action Required/Ready/Error）、My Quests 看板 |
| 中间：会话区 | 对话记录、执行步骤、输入框（@引用/模型选择/语音）、变更概览 |
| 右侧：功能区 | 概要（Progress/引用）、审查与提交（Diff/Git）、终端/浏览器/Spec/Supabase |

## 拓展功能入口
- **知识中心**：Repo Wiki + 知识卡片 + Memory
- **插件市场**：官方插件扩展能力
- **设置**：系统与偏好配置

## 平铺布局
支持拖拽拆分多窗格，并行比对多任务输出。布局跨会话保留。

## 注意事项
- 任务开始后不能切换模式
- 编辑消息会触发工作区文件回滚
