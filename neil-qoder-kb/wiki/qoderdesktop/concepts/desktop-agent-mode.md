# Agent 模式（Desktop）

> 智能体模式的完整决策、工具使用与多文件编辑机制——自主拆解任务、感知环境、调度工具、端到端交付。

## 概述

Agent 模式是 Qoder Desktop Editor 中的自主编码模式。具备自我决策、环境感知与工具调度能力，可利用项目搜索、文件编辑、终端访问等工具高效完成编码任务。

## 核心能力

| 能力 | 说明 |
|------|------|
| 项目级更改 | 自主拆解任务并修改多个文件，支持快照回滚 |
| 计划制定 | 生成分步待办事项供审阅（空心圈→旋转圈→复选框） |
| 自动环境感知 | 自动检测框架、技术栈、代码文件和错误信息 |
| 工具使用 | 文件读写、代码查询、错误排查、MCP 工具自动发现 |
| 命令执行 | 自主决定并在终端中运行命令（可配置允许列表） |

## 多文件编辑流程

1. **正在生成**：基于任务拆解生成代码建议
2. **正在应用**：将建议与原始文件集成
3. **已应用**：等待审阅（可逐处或批量接受/拒绝）

## 多轮交互

完成当前会话后可继续提交补充查询。Qoder 合并先前代码更改并生成新变更。Revert 按钮可回滚全部变更。

## 命令执行策略

- 默认每条命令执行前需确认
- 后台任务显示"在后台执行"指示器
- 可在设置中配置自动执行允许列表（逗号分隔）

## MCP 工具集成

支持与 MCP 服务集成，可连接第三方 MCP 应用市场一键安装。
