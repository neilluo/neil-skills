# Waker（数字员工）

> QoderWake 的核心执行单元——本机部署的 AI 数字员工实例，具备岗位、名字、人设和专长。

## 概述

Waker 是 QoderWake 中的数字员工实体。每个 Waker 绑定一个角色（Role），拥有独立的记忆、技能、连接器和权限配置。Waker 可以通过对话任务、自动任务或群组任务被驱动执行工作，7×24 小时持续运行。

## 详细内容

### 创建 Waker

1. 打开控制台（`http://127.0.0.1:19820`），点击左侧"创建 Waker"按钮
2. 选择角色模板（预置 7 种）或选择"自定义角色"
3. 填写基本信息：名字、头像、简介（预置角色会自动填充）
4. 保存后进入引导流程（推荐挂载技能、接入渠道）

### Waker 详情页

| 目录 | 功能 |
|------|------|
| **首页** | 状态、入职天数、触发任务数、对话任务数、工作热力图 |
| **项目** | 绑定代码仓库或本地目录（支持多源） |
| **触发任务** | 管理自动任务（增/删/改/暂停） |
| **对话任务** | 历史对话记录，可继续聊 |
| **记忆** | 长期认知条目（浏览/搜索/编辑） |
| **技能** | 安装/上传/开关技能包 |
| **连接器** | 对接外部工具/服务 |
| **权限** | 工具防护 + 文件防护 + 内置工具策略 |

### 驱动方式

Waker 支持三种任务驱动方式：
- **对话任务**：直接聊天派活，实时交互
- **自动任务**：定时/事件/API 触发，无人值守
- **群组任务**：多 Waker 协作，Leader 拆解调度

### 产品理念

*"Always awake, always working."* — 7×24 小时数字员工。
