# Role（角色模板）

> 定义 Waker 岗位特性的模板——预置 7 种职能角色，同时支持完全自定义。

## 概述

Role 是 Waker 的岗位蓝图，决定了员工的人设、典型工作流、核心技能集和默认行为。QoderWake 当前提供 6 种预置职能角色 + 1 种自定义角色，覆盖软件研发全链路。

## 详细内容

### 预置角色矩阵

| 角色 | 岗位特性 |
|------|----------|
| **后端工程师** | API 开发、数据建模、服务集成、性能优化、线上稳定性。增量交付、测试验证、约定优先。自动分析 Bug/Issue，改完代码提 PR。 |
| **前端工程师** | 组件架构、视觉语言、响应式适配、无障碍优化、性能调优。增量交付、分层验证、基于证据校验。 |
| **测试工程师** | 测试计划、端到端测试、缺陷复现、基于证据报告。不运行单元测试，不修复问题。 |
| **产品经理** | 目标驱动需求管理、PRD 生成、用户反馈分析、竞品研究、发布沟通。外部写入设审批门禁。 |
| **数据分析师** | 问题框定、指标口径、数据收集（钉钉文档/表格 MCP）、数据诊断、市场背景、证据化建议。 |
| **内容运营** | 账号定位、热点洞察、内容日历、小红书笔记创作、视觉素材 brief、审批后发布、评论互动、数据复盘。 |
| **自定义** | 完全自定义岗位工作方式与工作流，可挂载 MCP、Skill 等任意配置。 |

### 自定义角色

选择"自定义角色"时，建议提供完整信息以提升效果：
- 角色定位与核心职责
- 工作流程描述
- 所需技能配置
- MCP 等工具能力配置

### 角色与 Waker 的关系

- 一个 Role 可以被多个 Waker 复用
- 创建 Waker 时选择 Role 后，名字/头像/简介会自动填充
- 预置角色的默认配置可按需调整
