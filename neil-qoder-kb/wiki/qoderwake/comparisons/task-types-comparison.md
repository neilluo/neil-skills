# 任务类型对比：对话 vs 自动 vs 群组

> 三种任务驱动方式的选型决策矩阵——根据场景特征选择最合适的驱动模式。

## 概述

QoderWake 的三种任务类型各有所长，选错会导致效率浪费或交互不足。本页提供选型决策矩阵和典型场景映射。

## 详细内容

### 决策矩阵

| 维度 | 对话任务 | 自动任务 | 群组任务 |
|------|----------|----------|----------|
| **交互深度** | 高（实时追问） | 低（无人值守） | 中高（可介入） |
| **触发方式** | 手动输入 | 定时/事件/API | 手动发起 |
| **参与者** | 1 用户 + 1 Waker | 0 用户 + 1 Waker | 1 用户 + N Waker |
| **适合复杂度** | 中等 | 简单-中等 | 高 |
| **审批控制** | 实时弹卡片 | 按权限策略 | 实时弹卡片 |
| **最佳场景** | 一次性任务/探索性工作 | 周期性/事件驱动 | 跨角色协作 |

### 场景映射

| 场景 | 推荐类型 | 原因 |
|------|----------|------|
| 排查单个 Bug | 对话 | 需要实时追问和方向调整 |
| 每日代码扫描 | 自动（定时） | 周期性，无需交互 |
| 新 Issue 自动修复 | 自动（事件） | 事件驱动，无需人工触发 |
| CI 结束后触发部署检查 | 自动（API） | 外部系统集成 |
| 产品方案讨论 | 群组 | 需要产品+研发+测试多角色 |
| 竞品分析报告 | 群组 | 多视角综合分析 |
| 快速问一个配置问题 | 对话 | 简单直接 |

### 何时升级任务类型

```
对话任务 → 自动任务：当你发现自己反复对同一 Waker 说相同的话
对话任务 → 群组任务：当一个 Waker 搞不定，需要多角色配合
自动任务 → 群组任务：当自动产出需要多人 review 和迭代
```
