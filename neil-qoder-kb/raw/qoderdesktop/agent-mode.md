# Agent 模式

智能体模式具备自主决策、环境感知与工具调度能力。利用项目搜索、文件编辑、终端访问等工具高效完成编码任务。支持配置 MCP 工具扩展能力。

## 核心功能

- **项目级更改**：自主拆解任务并修改多个代码文件。支持多轮对话进行代码优化或快照回滚。
- **计划制定**：创建分步计划供审阅。复杂任务推荐使用 Quest 的 Spec 驱动模式。
- **自动环境感知**：自动检测项目框架、技术栈、所需代码文件及错误信息，无需手动补充。
- **工具使用**：自主使用文件读写、代码查询与错误排查等内置工具，支持自动发现 MCP 工具。
- **命令执行**：自主决定并在终端中生成运行命令。

## 待办事项规划

基于用户输入生成待办事项计划，将复杂问题拆解为有序步骤。进度状态：
- 空心圆圈：尚未开始
- 旋转圆圈：进行中
- 复选框：已完成

## 多文件编辑

每项修改包含"生成"和"应用"两个阶段：
- 正在生成：基于任务拆解生成代码建议
- 正在应用：将建议与原始文件集成
- 已应用：等待审阅

审阅时可逐处接受/拒绝，支持文件级批量操作。

## 多轮交互迭代

完成当前会话后可继续提交补充查询。Qoder 会合并先前代码更改并生成新变更。可点击 Revert 按钮回滚全部变更。

## 编程工具

文件搜索、文件读取、目录遍历、语义符号检索、文件修改、错误信息获取、命令执行等。Agent 根据返回结果规划下一步。

## 命令执行

Agent 根据需求自主选择并运行命令。默认每条命令执行前需确认。后台任务显示"在后台执行"指示器。可在设置中配置自动执行允许列表。

## MCP 工具

支持与 MCP 服务集成，可连接第三方 MCP 服务的应用市场一键安装。
