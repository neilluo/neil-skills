# 快速开始

本文将带你通过实操项目，以个人用户的身份体验 Qoder 的核心功能。完成后，你将熟悉 NEXT（下一条编辑建议）、行间会话，以及右侧会话中的 Ask / Agent。当你需要自主委派长程、多步任务时，可打开 Quest 独立视窗。

## 步骤

### 1. 下载并安装 Qoder
1. 从 https://qoder.com/download 下载安装程序。
2. 双击文件开始安装。
3. 双击 Qoder IDE 图标启动 Qoder。

### 2. 登录
- 在 IDE 右上角点击用户图标，或使用键盘快捷键（⌘⇧, / Ctrl+Shift+,），选择登录。
- 在打开的网页中注册或使用 Google / GitHub 账号登录。

### 3. 打开项目
- 使用本地项目：⌘O / Ctrl+O 打开文件夹
- 克隆代码库：点击 Clone repo，输入 URL 或从 GitHub 克隆

### 4. 探索功能

**NEXT（下一条编辑建议）**
- 输入部分代码或自然语言描述需求
- 按 ⌥P / Alt+P 唤出建议
- 按 Tab 接受当前建议

**行间会话**
- 按 ⌘I / Ctrl+I 打开行间会话
- 输入请求并发送
- 按 ⌘⏎ / Ctrl+Enter 应用生成代码

**右侧会话（Ask / Agent）**
- 按 ⌘L / Ctrl+L 打开 Chat 面板
- 选择 Ask（问答模式）或 Agent（自主编码模式）
- Ask 以问答为主；Agent 适合多文件修改与实现

**Quest 视窗**
- 面向自主委派：在独立视窗中发起长程、多步任务
- 由 Agent 持续执行；可在同一工作台查看看板、进度与产物
