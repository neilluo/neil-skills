# 规则（Rules）

Qoder 支持为每个项目配置专属规则。规则存放于 `.qoder/rules` 目录中，仅对当前项目生效。可优化模型对编码偏好的适配，包括项目所用框架与代码风格。

## 工作原理

规则通过将预定义的上下文有策略地注入到提示中，引导 AI 的回答更一致地符合项目标准。

**存储与共享**：规则文件直接存放在项目目录中，通过 Git 等版本控制系统与团队共享。仅本地使用时添加到 .gitignore。

**限制**：所有活跃规则合计最多 100,000 字符（超出截断）。仅支持自然语言。

## 规则类型

| 类型 | 描述 | 使用场景 |
|------|------|----------|
| 手动引入 | 通过 @rule 手动应用 | 按需工作流，自定义提示词 |
| 模型决策 | 模型在 Agent 模式下评估并决定何时应用 | 场景化任务（如生成单元测试或代码注释） |
| 始终生效 | 适用于所有智能会话和行间会话请求 | 强制执行项目级标准（编码风格/文档格式） |
| 指定文件生效 | 匹配通配符模式的文件（如 *.js / src/**/*.ts） | 语言或目录特定规则 |

## AGENTS.md 兼容性

将 AGENTS.md 文件放入项目目录，Agent 自动识别并应用其中定义的规则。无需额外配置。

> 如果 AGENTS.md 与规则内容冲突，则规则内容优先。

## 最佳实践
- 保持简洁：聚焦且明确无歧义
- 结构清晰：使用项目符号、Markdown 格式
- 包含示例：提供"良好"的代码示例
- 迭代优化：根据模型输出不断完善
