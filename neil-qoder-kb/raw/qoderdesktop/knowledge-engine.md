# 知识引擎

知识引擎是 Qoder 的核心能力模块，负责自动沉淀和管理日常开发中产生的业务知识。让 Agent 在每一次对话中都比上一次更了解你的项目——减少重复踩坑，提升回答精度，同时降低 Credit 消耗。

## 三类知识来源

| 来源 | 说明 | 沉淀路径 |
|------|------|----------|
| **Repo Wiki** | 基于代码库自动生成的结构化文档，覆盖项目架构、模块关系与实现细节 | 代码侧自动生成 |
| **知识卡片（Knowledge Card）** | 从代码中提炼的高密度知识单元：架构文档、代码规约（Spec）、技术栈信息 | 生成 Repo Wiki 时自动提炼 |
| **对话记忆（Memory）** | 从对话中自动提炼的踩坑记录、决策依据和项目经验 | 对话侧自动提炼 |

三类知识汇入同一个引擎，无需人工整理，Agent 在需要时自动调用。

## 自动沉淀路径

- **代码侧**：生成 Repo Wiki 时，系统自动将代码意图、设计方案和上下文讨论提炼为知识卡片
- **对话侧**：与 Agent 交互过程中的踩坑记录、决策依据和项目经验，自动提炼为 Memory
