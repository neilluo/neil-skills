# 编辑器概览（Editor）

编辑器是 IDE 内的核心 AI 工作区：在代码编辑时可通过 NEXT 代码建议获得实时的代码预测与补全，并在智能会话面板中使用智能问答（Ask 模式）或智能体（Agent 模式）完成问答与编码协作。

## 智能会话面板

- 打开方式：⌘L / Ctrl+L
- 支持查看聊天记录（历史图标）

### 两种模式

| 模式 | 定位 | 特点 |
|------|------|------|
| Ask（智能问答） | 问答模式 | 基于上下文回答问题、提供建议，不修改代码 |
| Agent（智能体） | 自主编码模式 | 具备自我决策、环境感知和工具使用能力，端到端完成编码任务 |

### 输入建议
- 结构化请求：清晰说明目标和步骤
- 提供上下文：附上文件、图片、代码变更
- 明确预期：说明偏好或规范
- 迭代式反馈：分步迭代协作

## NEXT 代码建议

根据光标位置、上下文以及最近修改，自动预测并生成下一段代码。按 Tab 快速采纳。

## 会话独立窗口

支持将进行中的对话拆分到单独窗口运行，便于多任务并行监控和分屏对照。

## 行为推荐卡片

Agent 完成一轮任务后，自动展示推荐卡片：
- Review Code Changes：审查代码变更
- Run Feature Test：浏览器验证页面效果
- AI Suggestion：根据上下文自主判断
