# 记忆

> 来源: https://docs.qoder.com/zh/cli/memory

## 记忆类型

| 机制 | 谁来写 | 适合内容 | 作用域 |
|------|--------|---------|--------|
| AGENTS.md | 用户或团队 | 明确、稳定、每次会话都遵守的说明 | 用户级/项目级/本地项目级 |
| 自动记忆 | Qoder CLI | 从对话中学到的可复用信息 | 项目级；可选用户级 |

## AGENTS.md

### 常用位置

| 位置 | 用途 | 是否适合提交 |
|------|------|------------|
| `~/.qoder/AGENTS.md` | 跨项目通用偏好 | 否 |
| `<project>/AGENTS.md` | 团队共享项目规则 | 是 |
| `<project>/AGENTS.local.md` | 本机项目私有说明 | 否 |

### 加载逻辑

项目记忆只做"向上查找"，不扫描子目录：
- 从当前工作区目录向父目录查找，默认到 .git 所在目录为止
- 子目录记忆按需加载（访问子目录文件后补充）

### @导入

`@path/to/file` 引入其他文件，相对于 AGENTS.md 所在目录解析。
- 支持相对/绝对/~/ 路径
- 代码块中的 @... 不触发导入
- 项目外导入需显式批准
- 递归展开有深度限制

## 自动记忆

### 启用

```bash
QODER_MEMORY=1 qodercli                    # 启用项目级
QODER_MEMORY=1 QODER_MEMORY_USER=1 qodercli  # 追加用户级
```

### 四类内容

| 类型 | 用途 |
|------|------|
| user | 用户角色、长期偏好 |
| feedback | 用户纠正或确认 |
| project | 项目背景、约束、决策原因 |
| reference | 外部系统、文档位置 |

### 存储位置

```
~/.qoder/projects/<project>/memory/  # 项目级
~/.qoder/memory/                      # 用户级（需启用）
```

每个目录含 MEMORY.md 索引 + 主题文件。

## 管理

- `/memory` — 打开记忆概览
- `/memory manage` — 管理自动记忆主题文件
- 自然语言："记住这个项目需要先启动 Redis" / "忘记之前关于旧部署脚本的记忆"
