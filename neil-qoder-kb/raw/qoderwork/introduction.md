# 简介

QoderWork 是一款桌面端智能工作助手，将 Qoder 的 Agent 能力从代码领域扩展到日常工作场景。通过简单的自然语言对话，就能完成文件整理、数据处理、文档生成等任务，自动化你的多种场景。

传统 AI 工具：你问，它答，动手还得靠自己。
QoderWork：你说需求，它交付结果。

## 核心能力

- **文件处理**：读取、编写、整理和转换文档、表格、演示文稿和 PDF
- **浏览器自动化**：自动导航网页、填写表单、提取数据，完成多步骤 Web 操作
- **桌面控制**：直接操控桌面应用程序——点击、输入、滚动，与任何应用交互
- **定时任务**：设置周期性或一次性自动执行的任务
- **IM 频道**：连接钉钉、飞书等即时通讯平台
- **技能与扩展**：通过社区技能、自定义工作流、MCP 服务器和第三方连接器扩展能力
- **语音输入**：用语音代替打字，自然口述需求
- **意识**：跨会话记忆与协作风格个性化

## 典型场景

| 场景 | 说明 |
|------|------|
| 文件整理 | 自动识别文件类型，智能整理项目文件 |
| 照片管理 | 按时间、地点、主题自动分类整理本地照片 |
| 数据分析 | 分析数据结构，生成统计报表与可视化图表 |
| 文档创作 | 撰写报告、制作演示文稿、处理表格数据 |
| 研究整合 | 汇总多源信息，提炼关键洞察 |

## 定价

使用 Qoder 账号登录，与 Qoder 共享 Credits 余额。

## FAQ

- 文件操作在本地完成，但文本内容会发送至大模型 API
- 只能访问明确授权的工作目录
- 适合任何想用 AI 自动化重复工作的人
