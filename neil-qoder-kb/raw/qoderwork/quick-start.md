# 快速开始

从下载到第一个任务交付，5 分钟体验完整流程。

## 1. 下载 QoderWork
- 访问 qoder.com/zh/qoderwork 下载
- macOS 14 及以上（Apple Silicon + Intel）
- Windows 10 及以上（64 位）
- 磁盘空间至少 500 MB

## 2. 登录账号
- 首次启动出现欢迎页，点击登录/注册
- 与 Qoder 桌面端、CLI 共用同一账户体系，Credits 余额共享
- 历史任务保存在本地设备，不跨设备同步

## 3. 认识工作界面
- 左侧：导航侧边栏（新任务/扩展/定时任务/IM频道/任务历史/设置）
- 右侧：工作区（对话/任务监控/产物）

## 4. 跑通第一个任务
- 点击新任务，保持默认通用工作台 + 标准模型
- 以"想要什么结果"为出发点描述需求

### 执行流程
1. **澄清问题**：复杂需求时先抛出澄清问题，清晰需求直接跳过
2. **任务监控**：左侧对话 + 右侧任务监控（待办计划/产物/Skills & MCP）
3. **收取产物**：总结 + 可下载文件（真实本地文件）

## 三个核心概念

| 概念 | 含义 |
|------|------|
| 澄清（Clarification） | 任务开始前的简短确认，对齐模糊需求 |
| 任务监控（Task Monitor） | 实时展示计划、工具调用、技能和文件的执行面板 |
| 产物（Artifacts） | 任务输出的具体文件——表格、幻灯片、报告、代码等 |
