# 定时任务（Scheduled Tasks）

定时任务让 QoderWork 从「你问它才动」变成「到点自己干」。

## 工作原理
到预定时间 → 自动新建对话任务 → 按 Prompt 执行 → 结果保存在该对话中。

执行时拥有与手动对话完全一样的能力：MCP 工具、连接器、技能、读写本地文件。

注意：由本地桌面客户端调度，以系统时区为准。电脑睡眠/关机时无法触发。

## 创建方式

### 方式一：对话中创建（推荐）
用自然语言描述「什么时间做什么事」，自动创建配置。

### 方式二：界面面板创建
定时任务页面 → + 新建 → 填写：任务名称、计划时间、Prompt、工作目录、模型

## 调度类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 不重复 | 指定日期时间执行一次 | 会议资料准备、截止日检查 |
| 间隔 | 每隔固定时间执行 | 价格监控、数据采集 |
| 每小时 | 每小时指定时刻执行 | 监控告警、状态同步 |
| 每天 | 每天指定时刻执行 | 每日早报、数据报表 |
| 每周 | 每周指定某天执行 | 周报草稿、竞品追踪 |
| 每月 | 每月指定某天执行 | 月度分析、账单汇总 |

## IM 推送
定时任务结果可配置推送到指定 IM 会话。
