# 电脑操控（Computer Use）

让 QoderWork 直接操作你电脑上的应用程序。

## 核心能力
- **屏幕感知**：读取目标应用窗口可见内容，持续截屏确认操作结果
- **鼠标与键盘控制**：点击、双击、拖拽、文字输入和键盘快捷键，像素级精度
- **后台自主执行**：后台驱动，不抢占前台焦点
- **跨应用流程**：多桌面应用之间切换，根据实时反馈动态调整

## 使用场景
- 操作没有 API 的桌面应用
- 跨应用工作流（切换窗口/复制数据/填表单）
- GUI 验证与测试
- 信息收集整合

## 系统要求
- macOS 14 或更高版本
- 需要辅助功能和屏幕录制权限

## 开启方式
扩展 → 连接器 → 计算机控制 → 开启

## 执行策略
| 策略 | 说明 |
|------|------|
| 每次询问（默认） | 每次操控桌面前征求确认 |
| 自动执行 | 直接执行，无需确认 |
| 禁用 | 完全关闭 |

## 操作流程
1. 截屏了解界面状态
2. 说明即将做什么
3. 执行操作
4. 再次截屏确认结果

## 限制
- 无法完成验证码、二步验证
- 需要截屏分析，比纯文本操作慢
- 界面复杂时精度可能不够
