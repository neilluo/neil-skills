# Query — 知识检索与回答 SOP（含回写门禁）

## 触发条件

- 用户提问且答案可能在知识库中
- 问题涉及已 ingest 过的领域/主题
- 用户显式要求"从知识库查"/"参考 wiki"

---

## 检索流程（4 层回退）

按优先级逐层检索，命中即停止回退：

### Layer 1: index.md 索引查询

1. 读取 `wiki/index.md`
2. 关键词匹配 + 语义匹配，定位相关页面
3. 若找到匹配条目 → 进入 Layer 2 读取页面
4. 若无匹配 → 继续 Layer 3

### Layer 2: Wiki 页面精读

1. 读取 Layer 1 定位到的 wiki 页面（可能多个）
2. 提取相关段落，组织回答
3. 检查交叉引用 `[[wikilink]]`，追踪关联页面补充上下文
4. 若内容充分 → 生成回答
5. 若内容不足 → 继续 Layer 3

### Layer 3: Raw 原始文件回溯

1. 根据 wiki 页面的 `sources` 字段定位原始文件
2. 读取 `raw/` 目录下的对应文件
3. 在原文中查找更详细的信息
4. 若找到 → 生成回答（并考虑回写）
5. 若仍不足 → 继续 Layer 4

### Layer 4: 外部搜索（WebSearch / QMD）

1. 使用 WebSearch 搜索最新信息
2. 或通过 QMD MCP 查询外部知识源
3. 标注来源为外部，证据等级为 `[inferred]` 或 `[derived]`
4. 生成回答（并评估是否回写）

---

## 回答格式

```markdown
## 回答

（正文内容）

### 来源
- [evidence-level] wiki/category/page-name.md — 相关段落
- [evidence-level] raw/YYYYMMDD-slug.md — 原始出处
- [evidence-level] https://external-url — 外部搜索结果
```

## 回写判定

### 触发回写的条件（满足任一即触发）

| 条件 | 说明 | 示例 |
|------|------|------|
| 跨页综合（3+ 页） | 回答融合了 3 个以上 wiki 页面的内容 | 综合了 A/B/C 三篇的对比分析 |
| 纠错补充 | 发现现有 wiki 内容有误或过时 | 官方文档已更新参数默认值 |
| 新话题 | 问题涉及知识库未覆盖的领域 | 用户问了一个全新的概念 |
| 深度解析 | 回答产生了有价值的深度分析 | 对比分析、架构决策推演 |

### 不回写的情况

| 情况 | 原因 |
|------|------|
| 一次性计算 | 无复用价值（如"帮我算个数"） |
| 纯 raw 转述 | 信息已在 raw 中完整存在，无需重复 |
| 已有覆盖 | wiki 已有对应页面且内容完整 |
| 时效性极强 | 信息会很快过时（如"今天的XX价格"） |

## 回写门禁规则（防幻觉传播）🚨

**核心原则：宁缺毋滥，不确定的不写入**

### 规则 1: 来源强制要求

回写内容**必须**有明确来源：
- raw 文件路径（如 `raw/20240115-api-guide.md`）
- 官方文档 URL（如 `https://docs.example.com/api`）
- 用户提供的可验证信息

**违规示例**：❌ "据我了解，这个参数默认值是 30"（无来源）

### 规则 2: 证据等级诚实标注

- 纯 LLM 推理结果**必须**标注 `[inferred]`
- **绝对不得**将 LLM 推理标为 `[primary]`
- 实战验证结论标注 `[derived]` 并说明验证条件

### 规则 3: 矛盾处理——不覆盖，而并存

当回写内容与现有 wiki 页面矛盾时：

```markdown
## 争议点

> ⚠️ [disputed] 关于 XX 的说法存在分歧

**说法 A**（来源：wiki/concepts/existing.md）：
- 内容 A

**说法 B**（来源：raw/20240120-new-source.md）：
- 内容 B

**判断建议**：待进一步验证，建议参考 [官方文档URL]
```

**绝对不得**直接覆盖已有内容。

### 规则 4: 无来源不回写

- 无来源的"合理推测"**不得**回写
- 即使逻辑上"很可能正确"，没有来源就不写
- 可以在回答中告知用户，但不落盘到 wiki

### 门禁检查清单

回写前逐项确认：

- [ ] 有明确来源（raw 路径 / URL / 用户确认）
- [ ] 证据等级标注正确（primary/derived/inferred）
- [ ] 不与现有内容矛盾（或已用 [disputed] 处理）
- [ ] 不是纯推测（有依据支撑）
- [ ] 有复用价值（不是一次性信息）

## 回写执行步骤

通过门禁后，按以下步骤执行回写：

### 1. 组织内容

按 wiki 页面标准格式组织：
- frontmatter（created/updated/sources/evidence）
- 概述 / 详细 / 交叉引用 / 来源 四段落

### 2. 放入对应目录

根据内容类型决定目录：
- 具体工具/服务/模块 → `wiki/entities/`
- 原理/模式/方法论 → `wiki/concepts/`
- How-to/最佳实践 → `wiki/guides/`
- A vs B 分析 → `wiki/comparisons/`

### 3. 添加 [[wikilink]]

- 新页面中引用相关已有页面
- 已有页面中添加对新页面的反向引用

### 4. 更新 index.md

在对应分区添加：
```
- [[new-page-name]] — 一句话描述
```

### 5. 记录到 log.md

```
| YYYY-MM-DD | 📝 Query 回写 | 用户问题摘要 → 新增/更新 page-name |
```
