## §5.5「注意事项」逐字引文（五句，主控逐字复核全部准确）

> 生效优先级由路由级向下递减：MCP/路由级 → Model API 级 → Agent API 级 → 域名级 → 实例级

> 实例级规则是兜底规则，实测在自定义 HTTP 类型 Model API 链路上可能不触发

> Model API 级规则在当前控制台版本下，自定义 HTTP 类型 API 不出现在可选列表中

> 域名必须精确填写，不能使用通配符 `*`

> 规则页必须显示「当前生效状态：已生效」
