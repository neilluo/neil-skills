# 技能市场

# 技能市场介绍

✨秒悟Meoo技能市场是秒悟平台面向开发者与普通用户提供的技能集合页面。技能市场中汇集各类开箱即用的AI技能，涵盖开发、测试、回复、文档、数据、设计、效率、运维等多种类型。用户可直接浏览、查看、一键使用技能，也可上传、下载技能，快速满足日常开发、办公自动化、业务场景落地等需求。

# 技能市场使用说明

## 搜索技能

✨在搜索框中输入想要搜索的技能，即可查询搜索需要的技能

<Note>
  秒悟 Meoo 技能市场搜索功能融合了**AI 语义搜索**技术，支持基于用户意图的动态检索。

  用户可直接通过自然语言描述需求（例如：“请帮我找一个能做财务报表的技能”），系统即可智能识别意图并精准定位相关技能。
</Note>

## 浏览技能

1. 技能市场集合了官方和个人上传的各种技能，可以在 **全部技能** 或 **我创建的** 中进行浏览查看，也可根据**通用、开发、UI设计、测试、文档、数据、效率**这些技能标签查找自己感兴趣的技能。
   <Note>
     点击 **添加**，再点击 **使用技能**，即可立即在创建应用的对话框中使用技
   </Note>
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/BdZLekJDYqqbEacD/images/image-93.png?fit=max&auto=format&n=BdZLekJDYqqbEacD&q=85&s=e5d44b24fbbe89f70b94cf050fb8bd87" alt="Image" width="1168" height="682" data-path="images/image-93.png" />
   </Frame>
2. 对于感兴趣的技能，可点击 **查看详情** 进入技能详情页浏览技能详细信息。
   * 对官方或他人创建的技能，在详情页面中可添加为常用技能、复制分享技能链接、下载技能。
     <Frame>
       <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/d14a15d78ce5ae40a3ebb0b20152ca8e.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=49145ecbf554d4a006e79eaeda04deda" alt="D14a15d78ce5ae40a3ebb0b20152ca8e" width="2256" height="1264" data-path="images/d14a15d78ce5ae40a3ebb0b20152ca8e.png" />
     </Frame>
   * 对我创建的技能，在详情页面中可使用技能、改造技能、设置技能访问权限、复制分享技能链接、下载技能到本地、删除技能。

## 上传技能

✨技能市场还支持上传本地已有技能包。

1. 点击**上传技能**，点击选择本地技能或拖拽zip包到指定区域。
