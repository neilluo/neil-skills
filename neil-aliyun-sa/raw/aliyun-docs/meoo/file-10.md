# 秒悟更新日志

## 2026/7/03

**新增「沙箱手动重启」功能**：当沙箱出现内存溢出、进程崩溃或运行异常，您可在会话框中输入“/”唤起命令菜单，选择“重启沙箱”即可强制重置环境，快速恢复开发状态。

## 2026/7/02

**上线「预览页手动微调」功能**：在网页端预览页面，可直接对文案、图片进行可视化编辑并实时生效。操作路径清晰四步走：① 点击右上角「手动微调」按钮 → ② 选中目标元素（如文字或图片）→ ③ 在左侧面板替换内容或上传图片 → ④ 点击「应用」即刻同步。让细节调整无需重新生成，创意打磨更高效。

> 使用注意事项：
>
> * 当前仅支持网页应用开启微调，手机App及小程序暂不支持；
> * 仅新建项目自动透出该功能，历史项目暂不支持升级启用。

## 2026/6/28

**秒悟支持「手机端浏览器访问」**：秒悟现已适配移动端 H5。此前您仅能在电脑端使用，现在只需通过手机浏览器访问 [meoo.com](http://meoo.com)，即可开启完整对话创作。灵感不等待，创作无界限——无论是通勤路上、咖啡馆里还是出差途中，掏出手机即可随时将想法转化为可上线的网站和应用。

## 2026/6/22

**支持「前端项目导入」**：点击秒悟主页对话框下方的「+」按钮，选择「导入秒悟项目」，即可快速接入现有工程。注意，当前仅支持导入从秒悟导出并在本地修改后的前端项目。支持React/Vue+Vite/Webpack、纯 HTML、微信小程序项目，需上传ZIP压缩包格式（最大100MB）。上传后系统会先验证项目结构与内容安全，通过后创建为新的秒悟项目。

## 2026/6/18

**上线 「GLM-5.2 模型」**：GLM-5.2 支持 1M 无损超长上下文，具备卓越的编程与工程能力，可自主完成复杂工程任务的全链路开发，适用于长程交互、代码生成等场景。

## 2026/6/10

**推出「Meoo CLI」**：meoo cli 是秒悟（Meoo）官方推出的命令行工具，让 Claude Code、Codex、Cursor、Qoder、Qoderwork等本地 agent 在帮你写完前端代码后，能直接接管「数据库、用户登录、文件存储、百炼模型服务、部署上线」的所有云端工作。

## 2026/6/09

**生成应用支持「手机号/邮箱注册登录」**：秒悟生成的应用现支持**真实的手机号与邮箱验证登录功能**。用户只需通过自然语言描述需求，即可自动构建完整的身份认证系统，满足会员管理、个性化服务等复杂业务场景。请注意，该服务包含**额外计费**：短信和邮箱分别有20条免费额度，超出后将按「短信35积分/条、邮箱2积分/条」向应用所有者收取。

**支持「中文自定义域名绑定」**：生成应用现支持配置中文自定义域名，突破传统英文域名限制，提升链接的品牌辨识度与亲和力，更契合国内用户的访问与记忆习惯，助力本土化高效传播。（该功能仅限MAX套餐用户）

**新增「应用访问权限管控」**：在发布应用时提供“互联网公开”、“指定人访问”和“仅自己访问”三种权限选项，增强了应用分发的安全性与灵活性，确保敏感数据与内部工具的访问隔离。其中，“指定人访问”仅面向秒悟用户开放，支持通过秒悟昵称精准添加访问对象。

## 2026/6/08

**优化「模式记忆功能」**：首页对话框现会自动记录用户上次选择的生成模式（如 Agent、Swarms 等）。下次打开时默认保留该设置，无需重复切换。这一改进可记住用户的模式使用习惯，减少前置配置工作，提升创作流畅度。

## 2026/6/05

**支持「小程序生成」**：秒悟新增支持小程序生成。不需要先学习小程序工程结构，也不需要在本地搭建开发环境；只要把需求讲清楚，平台就会生成一个可预览、可继续修改、可提交到微信审核的小程序项目。适合已经有业务想法、活动需求、商品服务或内部工具，希望尽快做成微信小程序的个人、商家和团队。

## 2026/6/04

**上线「Qwen-3.7-Plus 模型」**：新增支持 Qwen-3.7-Plus 多模态混合智能体模型，全面升级视觉-语言能力。该模型能够感知真实世界场景、读取屏幕并操作 GUI、基于视觉参考生成代码、端到端导航移动应用，同时保持了在编码、工具使用和生产力工作流的完整智能体能力。适用于需要强视觉理解、高保真复原和自动化交互的复杂任务场景。

## 2026/5/27

**新增「附件上传格式」**：在原有 PDF、Word、Excel、PPT、TXT、Markdown、CSV、SVG 支持基础上，新增对 **HTML、HTM、CSS** 格式文件的支持。

## 2026/5/26

**新增「对话反馈功能」**：在每条 AI 输出结果下方，可通过 👍 / 👎 图标提交正向或负向反馈。您的真实反馈将帮助我们持续优化模型逻辑与生成质量，让秒悟更懂您的开发意图，实现更精准的 Vibe Coding 体验。

**新增「单行数据上传限制」**：为保障云服务的高可用性与连接稳定性，现对云服务中数据表单行添加操作设置 **1MB 大小上限**。对于图片、视频等大文件或大对象，建议上传至 「云服务-文件」 存储，云服务的数据表里只存储引用链接。

## 2026/5/25

* **上线DesignMode：让 AI 生成的代码「看得见」**——*整体审美提升，多设计方案生成，设计调整不用消耗积分。*
  * **对话即可生图，直接插入项目** 你可以用对话描述想要的界面风格，Meoo 生成效果图后一键插入到项目结构中，符合你想要的品牌和项目调性。不只是生成一张素材图。
  * **可视化风格探索** 在规划阶段就能看到应用的视觉预览，不再是对着一堆文字描述想象最终效果。产品和设计协同时，Plan Mode 的预览可以直接当原型看。
  * **预设风格选择** 不需要从零描述设计语言。预置了多种主流风格，选一个，后续生成自动对齐。风格会应用到组件、配色、排版，不做「套模板」，而是按风格重新生成代码。
* **BrowserUse：让 AI 替你操作浏览器**——*Meoo 不只是生成代码，它还能自己打开网页、填表单、抓信息。* BrowserUse 是浏览器自动化能力。与传统的 RPA 或脚本不同，它是 AI 理解网页结构后自主操作的——你告诉它目标，它自己决定怎么点。 **典型场景**:
  * **数据&信息采集**: 「帮我抓取这个页面上的所有商品信息和价格，整理成表格」
  * **表单填写**: 「帮我打开xx内容平台，帮我自动在帖子下面发评论」→ 填信息、过验证，但要小心平台的风控封号危险⚠️
  * **竞品对比**: 「打开这三个竞品首页，截图关键模块，告诉我差异」
  * **测试辅助**: 「帮我把刚生成的页面跑一遍，检查有没有明显的交互问题」
* **Meoo 助理 Agent + 记忆能力**——*不是帮你写代码的 Agent，是帮你记住一切的 Agent。* Meoo 助理是独立于代码 Agent 的「**私人管家**」角色，可以和你探讨、分析方案。代码 Agent 负责把需求变成代码，Meoo 助理负责让整个体验变智能——它知道你是谁、你在做什么、你上次聊到哪了、方案有没有问题。 另外本次会上线「**可管理**」的Meoo全局记忆能力，知道你的偏好、风格、记忆分级（项目记忆和个人记忆）。

## 2026/5/15

**上线 「GLM-5.1 模型」**：新增支持 GLM-5.1 模型，其在代码逻辑推理方面表现优异，擅长处理复杂编程任务。由于该模型对算力要求较高，运行时会消耗较多积分，建议根据任务复杂度灵活选择。

## 2026/5/11

**新增「积分充值阶梯折扣」功能**：实行“多充多省”优惠机制，设置三档折扣梯度——充值≥10万积分享98折；≥50万积分享95折；100万积分享88折。用户在积分增购页面的自定义模块输入目标积分数值后，系统将自动匹配并应用对应层级的折扣优惠。

## 2026/5/08

**升级「自动续费」逻辑**：自动续费扣款时间从“到期前 9 天”缩短为“到期前 1 天”。由于规则升级，2026年4月16日及之前初次付费的用户，5月份扣款仍按原规则（提前9天）执行，后续订阅周期正常提前 1天 自动续费。2026年4月17日及之后初次付费的用户，直接适用新规则，均在到期前 1天 自动续费，不受影响。

## 2026/4/29

**新增「Plan 模式」**：引入“先规划，后执行”的工作流程。模型将首先生成详细的需求文档，待用户确认无误后，再自动开始具体任务的执行，确保结果更符合预期。

**新增「取消发布应用」功能**：支持将已发布的应用取消发布。操作后，应用将从社区下架（如已上架），并立即停止公网访问权限，确保业务安全可控。
