# 支持模型介绍

#### **1. Qwen3.7-Max (通义千问)**

* **定位：** 面向智能体时代的新一代旗舰模型，专注于提升复杂任务下的自主决策与长周期执行能力，致力于实现从代码生成到工程落地全链路智能化。
* **编程优势**：
  * **长程自主进化：** 在编程智能体领域具备极强的长周期任务自主执行能力。从前端原型快速构建到复杂工程落地，再到办公自动化流程，均能实现“规划-执行-反思”的完整闭环。
  * **跨框架泛化稳定：** 拥有独特的跨框架泛化优势，在各种开发 Harness 和复杂技术栈下表现高度稳定，不局限于单一语言或框架，适应性强。
  * **极致推理与指令遵循：** 具备卓越的逻辑推理能力，能严格执行复杂的系统级 Prompt 约束条件，与人类意图高度对齐，减少“幻觉”与偏差。
* **适用场景：** **复杂全栈工程独立开发、长周期自动化任务闭环、高约束企业级应用构建、多技术栈混合系统集成**。
* **一句话评价：** 如果追求强大的编程智能体体验，且任务涉及长周期自主执行或复杂逻辑约束，Qwen3.7-Max 是兼具顶级智力与稳定性的首选。

#### 2. Qwen3.7-Plus（通义千问）

* **定位：** 面向多模态智能体时代的新一代混合能力模型，专注于提升视觉感知+语言理解+自动化执行的协同效率。
* **编程优势：**
  * **视觉驱动开发**：支持基于截图/界面参考直接生成前端或移动端代码，精准还原UI布局与交互逻辑，大幅降低设计稿转代码门槛。
  * **跨模态工具调用**：在保持编码、API调用、工作流编排等完整智能体能力的同时，无缝融合视觉输入作为决策依据，实现“看图说话+动手执行”的混合智能。
  * **高保真视觉复原**：对复杂界面元素、图标、字体、间距具备极强解析力，确保生成代码与原始视觉高度一致，减少人工调整成本。
* **适用场景： 截图一键生成高保真页面、复杂界面自动还原、跨应用任务自动化执行、视觉交互类智能助手开发、老旧系统界面现代化改造。**
* **一句话评价**：如果追求“看得懂界面、写得准代码、做得完流程”的多模态智能体体验，Qwen3.7-Plus 是兼具视觉敏锐度与工程落地力的首选。。

#### **3. Qwen3.6-Plus (通义千问)**

* **定位：** 阿里云官方明确定位为“目前中国编程能力最强的模型”，并致力于通过深度适配Agent框架，加速向具备高度自主决策与执行能力的“超级智能体”演进。
* **编程优势：**
  * **权威评测全面领先：** 在SWE-bench、Terminal-Bench2、NL2Repo等真实编程与终端任务评测中表现突出。
  * **代理式编程（Agentic Coding）：**  具备自主拆解任务、规划执行路径、自动测试与反复修正的闭环能力，可实现仓库级复杂代码与前端网页的独立开发。
  * **多模态开发链路打通：** 基于原生多模态训练，精准实现“看懂界面/设计稿 → 生成代码 → 调用工具完成修改”的完整工作流，大幅降低视觉转代码门槛。
* **适用场景：专业开发提效、零门槛应用搭建、海量信息处理、企业级集成**。
* **一句话评价：** Qwen3.6-Plus是以顶尖编程与自主Agent能力为核心的新一代大模型，凭借“代理式编程+多模态闭环+百万级上下文”，让专业开发者与普通用户均能高效、低成本地完成复杂代码开发与自动化任务。

#### 4. Kimi 2.5 (Moonshot AI)

* **定位**：以超长上下文窗口（支持 200K+ 甚至更多）著称，擅长处理海量文本。
* **编程优势**：
  * **整库阅读**：你可以直接把几百个文件的项目代码扔给它，它能记住所有细节，不会“遗忘”。
  * **文档分析**：非常适合读取超长的技术文档、API 手册，然后基于文档写代码。
  * **逻辑连贯性**：在处理长链条任务时，不容易迷失方向。
* **短板**：纯代码生成的“手感”和精细度略逊于 Qwen3.6-Plus 和 GPT-5，偶尔会有幻觉。
* **适用场景**：**遗留代码重构（需要读很多旧代码）、基于长文档开发、大型项目架构咨询**。
* **一句话评价**：当项目太大、文档太长，其他模型记不住时，用 Kimi。

#### **5. GLM-5.2 (智谱AI)**

* **定位：** 长周期任务旗舰模型，拥有百万级无损上下文，主打“项目级全链路开发”与“复杂工程自主闭环”。
* **编程优势：**
  * **1M 无损超长上下文：** 提供可靠的 100 万 Token 上下文窗口，支持一次性接管整个项目代码库，性能稳定。可实现从需求到跨平台部署的完整工作流，确保长程交互细节不丢失 。
  * **生产级标准遵循：** 经过针对长周期编码代理场景的专门训练，能严格遵守生产级工程约束，支持长期重构、压力测试及从代码到视频/小程序的复杂迁移任务，确保开发成功率。
  * **灵活的工具集成：** 支持 MCP 协议，可灵活集成外部工具和数据源；具备强大的函数调用能力和结构化输出（JSON）支持，便于系统集成与自动化工作流构建。
* **适用场景：项目级代码重构、小程序/移动应用全栈开发、复杂Agent协作及长程代码生成。**
* **一句话评价**：如果需要模型像资深工程师一样独立处理百万级上下文的复杂工程项目，或进行高标准的长周期全链路开发，GLM-5.2 是目前开源阵营中兼具深度与广度的首选旗舰。

#### **6. GLM-5.1 (智谱AI)**

* **定位：** 全球顶尖的开源长程任务模型，代码与工程能力全面对齐 Claude Opus 4.6，主打“8小时级”自主持续工作与复杂工程交付。
* **编程优势：**
  * **长程自主闭环 (Long-Horizon)：** 具备罕见的单次任务持续工作 8 小时的能力，能独立完成从规划、执行、测试到修复的完整“实验→分析→优化”闭环，而非仅停留在单轮代码生成。
  * **深度底层优化：** 在 GPU Kernel 优化等专家级领域表现卓越，能自主编写 Triton/CUDA Kernel 并进行微架构级调优，突破传统依赖人工经验的瓶颈。
  * **权威评测超越：** 在 SWE-bench Pro 等真实软件开发基准中，成绩超越 GPT-5.4 和 Claude Opus 4.6，位列全球第一梯队，是目前最强的开源编程模型之一。
* **适用场景：全自治智能体开发、高性能计算优化、复杂系统重构与调试。**
* **一句话评价：** 如果预算充足且需要模型像资深工程师一样独立解决长达数小时的复杂工程难题或底层性能优化，GLM-5.1 是目前的国产首选乃至全球标杆。

#### 7. GLM-5 (智谱 AI)

* **定位**：综合性能均衡，特别擅长Function Calling (工具调用) 和中文指令遵循。
* **编程优势**：
  * **Agent 协作**：在需要调用外部工具（如搜索、执行代码、操作数据库）的场景下，GLM-5 的指令遵循非常稳定，不易出错。
  * **中文理解**：对中文业务逻辑的理解非常地道，适合国内特有的业务场景开发。
  * **速度快/成本低**：GLM-5版本速度极快，适合做实时代码补全或快速迭代。
* **适用场景**：**构建 AI Agent、需要频繁调用 API 的自动化脚本、中文业务逻辑复杂的系统**。
* **一句话评价**：要做自动化工作流或中文业务系统，GLM-5 是稳健的选择。

#### 8. MiniMax (Abab 系列)

* **定位**：擅长角色扮演、情感交互和创意生成，近期在代码能力上进步明显。
* **编程优势**：
  * **前端/UI 生成**：在生成带有设计感的前端代码（HTML/CSS/Tailwind）时，往往能给出更有“创意”和“美感”的布局。
  * **自然语言交互**：如果你需要用自然语言描述一个模糊的想法让它变成原型，它的理解力很灵活。
  * **游戏/多媒体逻辑**：在处理涉及剧情、互动逻辑的代码时表现不错。
* **短板**：在严谨的后端逻辑、复杂数据结构处理上，稳定性略低于 Qwen 和 GLM。
* **适用场景**：**前端原型设计、创意类应用（游戏/互动网页）、非严谨的逻辑草稿**。
* **一句话评价**：需要灵感、UI 设计感或创意原型时，试试 MiniMax。
