# 快速开始你的第一个vibe应用

# **开发应用**

从一个简单的任务入手，在秒悟Meoo开发你的第一个 AI 编程项目。本教程以开发一个网页端活动海报生成器为例，演示如何快速使用秒悟Meoo开发并部署一个网页应用。

## **步骤一：输入你的需求**

1. 创建应用并输入你的需求。在秒悟Meoo首页，单击桌面端应用
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/pyv3EkV9rBZPAe_b/images/4ef91123c2216fe5d6d1777b68972997.png?fit=max&auto=format&n=pyv3EkV9rBZPAe_b&q=85&s=790a95ff16fa86965d9ffe0054abfe34" alt="4ef91123c2216fe5d6d1777b68972997" width="2256" height="1264" data-path="images/4ef91123c2216fe5d6d1777b68972997.png" />
   </Frame>
2. 在文本框输入你的提示词 可以清晰且详细地描述应用的功能、界面设计、业务逻辑等方面的要求。例如，你可以输入以下指令：
   > 请开发一款‘企业创意海报生成器’网页应用。核心功能是：用户输入活动主题、时间、地点及宣传语后，系统能自动套用预设的设计模板（如商务、活力、节日风格）生成海报。界面布局要求左侧为表单输入区，右侧为效果实时预览区，并提供‘一键下载图片’按钮。整体设计需简洁现代，旨在帮助员工为内部邮件、文化活动快速制作出吸睛的宣传物料。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/1778489714960_3153cfbdeb614c34b4c1d5f77e209f16.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=61621543041e53b1c97b9b66d835de56" alt="1778489714960 3153cfbdeb614c34b4c1d5f77e209f16" width="2256" height="1264" data-path="images/1778489714960_3153cfbdeb614c34b4c1d5f77e209f16.png" />
   </Frame>
3. 也可以极简的输入一句话，让AI帮你润色完善细节（或者直接回车，模型也会自动补全一些细节）
4. （选择）选择编程模型。 秒悟Meoo 已集成 Qwen3.6-Plus、Kimi-K2.5 等主流的编程模型，用于开发应用。为了达到较好的开发效果，可以根据模型的官方介绍自行选择。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/48a410766de386baf152e160b23975e6.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=7ae9e50875cd293b2d87ccdd2c9a94b2" alt="48a410766de386baf152e160b23975e6" width="2256" height="1264" data-path="images/48a410766de386baf152e160b23975e6.png" />
   </Frame>
5. 在键盘中敲击回车，开始开发你的项目。 秒悟Meoo 会根据你输入的提示词来开始设计应用、创建项目，并自动为项目设置应用名称。

## **步骤二：预览与测试**

秒悟Meoo 收到你的需求之后，将立即启动需求分析，并规划开发流程和步骤，逐步生成应用的前后端代码。代码生成完毕后，自动构建并启动服务，以提供一个可视化的界面供你预览。你可以在预览区全面测试你的应用，查看其功能是否可用，如果发现应用存在问题或有新的需求，你可以随时反馈给秒悟Meoo ，它会根据你的反馈对代码进行调整。

## **步骤三：一键发布（部署）与分享**

完成应用的开发与测试之后，你可以在页面右上角单击**发布**，将秒悟Meoo搭建的应用部署成为一个公开可访问的在线项目，将你的创意和原型，转化为服务于真实用户的产品。
