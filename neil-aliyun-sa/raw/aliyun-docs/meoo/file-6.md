# 云服务能力介绍

## **什么是** 云服务 ？

Meoo秒悟 就像给你的应用配的一套“后台工具箱”。

如果不开启 秒悟 就只有纯前端代码，你做的东西更像“展示页”：能把内容显示出来，但无法实现用户登录、数据保存（比如留言、订单）、上传图片、多人同时更新这些功能；应用就算保存了数据，也只是保存在本地，换个浏览器/发送给其他人后是看不到的。

秒悟打包好了这些后台能力，集成了用户注册登录、权限管理、数据存储、文件存储、实时消息，启用后 秒悟 就能生成包含前后台功能的全栈应用。

## **Feature**

**✓ 原生文件上传**--大**文件**和**图片**处理更流畅

**✓ 实时消息推送**--支持**多人协作**与**即时通讯**场景

**✓ 独立数据库资源**--更强性能，更高**稳定性**，支持**按需扩容**

**✓ AI Coding 增强**--复杂系统与**多角色权限管理**游刃有余

数据库全链路功能升级，更多功能等你体验！

<Tip>
  Tips：数据库开启通过对话框输入指令即可，秒悟也支持自动识别按需启用云服务能力。
</Tip>

## 云服务操作

**✓ 数据操作**：云服务可进行CSV格式数据导入和导出、数据添加删除等操作。

**✓ 文件管理**：云服务中支持文件上传和URL生成，单文件上传上限50MB

**✓ 秘钥安全管理**：对接第三方服务的API Key，不要直接写在代码里，建议在云服务中创建密钥（Secret），将API Key填入密钥中，让AI通过引用密钥变量来使用。

**✓ 注册登录**：通过GoTrue 提供了开箱即用的多种认证方式，支持用户注册验证，以及邮箱、密码、手机号等多种登录方式，并具备灵活的扩展能力。
