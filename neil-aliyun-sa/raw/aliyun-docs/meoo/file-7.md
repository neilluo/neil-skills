# 开票流程指南

1. 点击【设置】 ，进入订阅与用量页面。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/12d84d04dafbe95745454757e7e68354.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=e65cf931a6c845dba3249ba6532800ca" alt="12d84d04dafbe95745454757e7e68354" width="2256" height="1264" data-path="images/12d84d04dafbe95745454757e7e68354.png" />
   </Frame>
2. 点击【订单】 ，然后点击【前往开票】 ，进入阿里云发票管理页面。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/938fb37e1f834aa57e281db7eb8ee8dc.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=198ebea6ab1d149c51bae00c20fcc4d1" alt="938fb37e1f834aa57e281db7eb8ee8dc" width="2256" height="1264" data-path="images/938fb37e1f834aa57e281db7eb8ee8dc.png" />
   </Frame>
3. 如果未进行实名认证，则先进行【实名认证】再开票。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/6d12a25c0d871741600f852f86958065.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=b33024cf3db0a3ec7891be1eab602ef3" alt="6d12a25c0d871741600f852f86958065" width="2256" height="1264" data-path="images/6d12a25c0d871741600f852f86958065.png" />
   </Frame>
4. 可选择按订单明细、按月账单或者按金额三种方式开票，然后选中需要开票的项目，点击【申请开票】。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/95f7c8d9a7abe7b5c89e6ade54ee7a66.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=25c74ff4bd6ed22223f040134dd562f8" alt="95f7c8d9a7abe7b5c89e6ade54ee7a66" width="2256" height="1264" data-path="images/95f7c8d9a7abe7b5c89e6ade54ee7a66.png" />
   </Frame>
5. **根据实际情况和需要**选择或填写 发票抬头、发票类型、接收邮箱、基本信息中的规格型号 ，点击【提交申请】。
   <Frame>
     <img src="https://mintcdn.com/alibaba-b47c397f/gtdh1P8HyRzTFXYK/images/ede55d63917e56c59ac25837ca7b7979.png?fit=max&auto=format&n=gtdh1P8HyRzTFXYK&q=85&s=fb614fba571b896532fec6ccb24a863e" alt="Ede55d63917e56c59ac25837ca7b7979" width="2256" height="1264" data-path="images/ede55d63917e56c59ac25837ca7b7979.png" />
   </Frame>
6. 耐心等待几分钟，待完成开票后，在发票管理页面中的【发票下载与退票】进行发票【下载】。

   </Frame>
