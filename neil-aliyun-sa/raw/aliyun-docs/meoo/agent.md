# 不同Agent模式差异

* **Agent -复杂任务**：深度推理，复杂需求、长任务处理
  * 任务非常复杂，涉及多个文件和技术栈。
  * 你对代码质量要求极高，不能容忍低级逻辑错误。
  * 你需要构建一个完整的、可运行的系统原型。
  * 你不介意等待更长的时间以换取更好的结果。
* **Swarms -蜂群模式**：蜂群并发，极致速度、更快交付
  * 任务简单、明确、单一。
  * 你正在探索思路，需要快速看到代码样例（Drafting）。
  * 你只是需要解释代码或进行简单的重构。
  * 你在赶时间，或者 Token 预算有限。
* **Plan - 规划模式：** 提前规划，步骤拆解、确认再执行
  * 任务涉及完整应用构建，需明确功能、架构及实施步骤。
  * 你希望在编码前审查整体计划，确保技术选型与逻辑无误。
  * 确认后系统自动连续执行，无需中途干预，兼顾效率与可控。
  * 你追求过程透明，避免黑盒操作导致的方向偏差或返工风险。
* **Design - 设计模式**：设计探索，多方案选择，择优后实现
  * 你还没有确定最终风格，希望先看到不同设计方向，再做判断。
  * 你在做视觉导向的页面，希望结果不只是“能用”，而是有明确的审美、层次和完成度。
  * 你不想围绕一个不满意的初稿反复修改，希望一开始就拥有可对比、可取舍的选择空间。
  * 你希望先确认设计方向，再进入正式制作，减少后续返工和沟通成本。
