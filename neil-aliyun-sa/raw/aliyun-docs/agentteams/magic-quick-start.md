AgentTeams 平台支持快速搭建和管理 AI Worker，并统一接入多种大模型供应商。本文介绍从服务开通到运行第一个 AI Worker 的完整操作流程，包括服务关联角色授权、实例创建、模型配置和 Worker 验证。  

## 准备工作
* 已开通 AgentTeams 服务。

## 步骤 1：创建服务关联角色
AgentTeams 通过服务关联角色访问相关云资源。首次登录控制台时，完成以下操作进行授权。

1. 登录 AgentTeams[控制台](https://agentteams.console.aliyun.com/)。

2. 首次访问时，提示**授权服务关联角色** ，点击**立即授权**。

## 步骤 2：创建实例
1. 点击**创建实例**。

2. 填写**实例名称** ，选择**地域** 、**专有网络**、**交换机**、**网络访问类型**。

3. 点击**立即创建**。

4. 点击**立即开通**。

5. 等待实例初始化完成。

## 步骤 3：配置模型
1. 在实例详情页左侧导航栏，点击**模型管理**。

2. 点击**添加模型** ，填写**模型名称** ，选择**模型供应商**。

3. 点击**创建**完成模型添加。

## 步骤 4：创建用户
1. 在实例详情页左侧导航栏，点击**用户管理**。

2. 点击**创建用户**。

3. 填写**用户名** 、**显示名称** 、**邮箱**。

4. 选择**认证方式**。

5. 点击**立即创建**。

## 步骤 5：创建Worker团队
1. 在实例详情页左侧导航栏，点击**Worker 团队**。

2. 点击**创建 Worker 团队**。

3. 在**1. 基本信息** 区域，输入**团队名称** 、**团队 Admin** 、**团队成员** 、**描述**。

4. 在**2. Team Leader 配置** 区域，选择**自定义创建**。

   1. 填写**Leader 名称**。

   2. **选择模型**。

   3. 输入**SOUL.MD** 、**AGENT.MD**的文件内容。

   4. 配置**技能绑定** 、**MCP Server 绑定**。

5. 点击**创建**。

## 步骤 6：创建 Worker
1. 在左侧导航栏，点击**Worker 管理**。

2. 点击**创建 Worker**。

3. 选择**自定义创建**。

   1. 填写**Worker 名称**。

   2. **选择模型**。

   3. 选择**所属团队**。

   4. 输入**SOUL.MD** 、**AGENT.MD**的文件内容。

   5. 配置**技能绑定** 、**MCP Server 绑定**。

4. 点击**立即创建**。

## 步骤 7：验证 Worker 团队
1. 在左侧导航栏选择**概览**。

2. 在**实例详情** 区域，开启**公网访问**开关。

3. 等待配置生效。

4. 在**连接点** 区域，点击**Element UI**右侧的**打开** ，前往**Element UI**的接入点页面**。**

5. 根据页面提示完成登录，并且验证Worker团队的功能。

至此，已完成 AgentTeams 实例创建、模型配置及第一个 Worker 团队的搭建。

## 了解更多
完成基础搭建后，可进一步探索以下功能：

* **用户管理**：邀请协作者共同管理 Worker 和模型资源。

* **监控与统计**：通过仪表盘查看 Worker 用量、模型调用次数和资源消耗。

* **MCP 服务**：为 Worker 集成外部工具能力，扩展应用场景。
