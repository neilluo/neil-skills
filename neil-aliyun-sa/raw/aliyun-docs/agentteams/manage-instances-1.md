AgentTeams 实例是资源隔离和管理的基本单元，每个实例维护独立的模型配置、Worker、团队和 MCP 服务，确保不同业务场景之间相互隔离。本文介绍如何创建、查看和删除 AgentTeams 实例，以及如何通过仪表盘监控实例运行状态。

## 实例概述
AgentTeams 实例是资源隔离和管理的基本单元。创建实例后，实例将独立维护以下资源，不同实例之间互不干扰：

* 模型配置

* Worker

* 团队

* MCP 服务

* Skill

## 创建实例
1. 登录 AgentTeams[控制台](https://agentteams.console.aliyun.com/)。

2. 在左侧导航栏顶部的下拉框中点击**创建实例**。

3. 填写**实例名称** ，选择**地域** 、**专有网络**、**交换机**、**网络访问类型**。

4. 点击**立即创建**。

5. 点击**立即开通**。

6. 等待实例初始化完成。

## 查看实例列表
1. 登录 AgentTeams[控制台](https://agentteams.console.aliyun.com/)。

2. 在左侧导航栏顶部的下拉框中选择已创建的实例。

3. 如需定位特定实例，在搜索框输入实例名称进行筛选。

## 查看实例详情
1. 在左侧导航栏选择**概览**。

2. 在**实例详情** 区域，查看以下实例信息：**状态** 、**名称** 、**实例 ID** 、**规格** 、**VPC** 、**创建时间**

## 开启公网访问
实例支持以下类型的**连接点** ：**Element UI**，**Matrix Server**。

默认仅提供私网访问，若需要公网访问，则执行以下步骤手动开启。

1. 在左侧导航栏选择**概览**。

2. 在**实例详情** 区域，开启**公网访问**开关。

3. 等待配置生效。

4. 验证公网访问开启成功：在**连接点** 区域，可以查看**公网** 的**内置域名**。

## 配置自定义域名
实例支持为公网**连接点** 配置**自定义域名** ，本文以**Element UI**为例，介绍配置步骤。

1. 在左侧导航栏选择**概览**。

2. 在**连接点** 区域，点击**Element UI**右侧的**配置**。

3. 开启**配置自定义域名**。

4. 选择**协议类型**：

   * **HTTP（明文传输）**：HTTP 协议不加密数据传输，建议仅在内部测试环境使用

   * **HTTPS（安全连接）** ：HTTPS 协议加密传输数据，还需要配置**安全证书**。

     1. 完成安全证书的创建，参考[创建SSL证书](https://help.aliyun.com/document_detail/2861493.html)。

     2. 返回当前控制台，在**安全证书** 区域，点击刷新按钮，点击**添加证书**。选择已创建的证书。

5. 填写**自定义域名**。

6. 添加**自定义域名**解析记录：

   * 添加CNAME记录，将**自定义域名** 解析到公网**连接点** 的**内置域名**。

   * 具体操作，请前往**自定义域名** 所属的DNS服务提供商并参考其文档。如果使用阿里云DNS服务，请参考[添加解析记录](https://help.aliyun.com/document_detail/2936415.html)。

## 配置NAT网关
默认实例无法访问公网上的资源或服务，若需要访问公网，则执行以下步骤配置NAT网关。

1. 在左侧导航栏选择**概览**。

2. 在**NAT 网关** 区域，点击**一键开通**。

3. 等待配置生效。

## 删除实例
**警告**

删除实例前，需确保实例内无运行中的 Worker。实例删除后无法恢复，请谨慎操作。

1. 在左侧导航栏选择**概览**。

2. 点击**释放实例**。

3. 弹出确认对话框后，确认删除操作。

## 配额与限制
* 每个阿里云账号在各地域可创建的实例数量存在上限。如需创建更多实例，请前往配额中心提交配额提升申请。
