API 产品分类用于对开放平台中的 API 产品进行归类与打标，便于在管理侧检索、筛选，以及在开发者门户中按分类浏览与展示。本文介绍如何创建和管理产品分类。  

## 概述
API 产品分类用于对开放平台中的 API 产品进行归类与打标，便于在管理侧检索、筛选，以及在开发者门户中按分类浏览与展示。

## 产品分类与 API 产品的关系
产品分类与 API 产品之间通过关联表建立多对多关系：

* 同一 API 产品可以绑定多个产品分类。

* 同一产品分类下可以包含多个 API 产品。

将 API 产品绑定到分类有两种方式：

1. 创建或更新 API 产品时，指定产品所属的分类。

2. 在分类详情页中，将指定产品添加到当前分类。

## 创建产品分类
1. 登录开放平台管理控制台。

2. 进入产品分类管理页面，点击新增产品分类。

3. 填写分类信息并保存。

## 编辑产品分类
在产品分类管理页面，找到目标分类并进入详情页，可修改分类的名称、描述和图标。修改后保存即可生效。  
**说明**

分类名称的命名规则与创建时一致：以英文字母开头，仅允许字母、数字、下划线与连字符，长度为 2～64 个字符。

## 管理分类下的 API 产品
在分类详情页中，可以将 API 产品添加到当前分类，也可以将已绑定的产品从分类中移除。具体操作如下：

### 添加 API 产品

1. 在分类详情页中，点击添加产品。

2. 从产品列表中选择目标 API 产品，确认添加。

### 移除 API 产品

1. 在分类详情页的产品列表中，找到目标产品。

2. 点击移除，确认操作。
