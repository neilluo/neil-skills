本文介绍如何编辑密钥内容以及如何删除密钥。  

## 编辑密钥内容
1. 前往[AI 网关控制台](https://apig.console.aliyun.com/)。

2. 在左侧导航栏，选择**密钥**。

3. 在**密钥** 列表页面，单击目标密钥名称**操作** 列下的**编辑**按钮。

4. 在**编辑密钥** 面板中单击**修改密钥内容** ，输入密钥内容，然后单击**确定**。

## 删除密钥
1. 前往[AI 网关控制台](https://apig.console.aliyun.com/)。

2. 在左侧导航栏，选择**密钥**。

3. 在**密钥** 列表页面，单击目标密钥名称**操作** 列下的**删除**按钮。

4. 在删除页面输入密钥名称，单击**删除**。

**说明**

密钥被其它资源引用时无法删除，需要先前往相关引用位置删除引用。
