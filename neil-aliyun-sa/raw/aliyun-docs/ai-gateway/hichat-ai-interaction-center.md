通过 HiChat AI 交互中心，可以与已订阅的 AI 模型进行实时对话，并启用 MCP Server 扩展模型的工具调用能力，在统一界面中完成文生文、文生图等智能交互任务。  

## 功能概述
HiChat 为开发者提供以下核心功能：

* 与已订阅的模型产品进行实时对话，支持文生文和文生图等场景。

* 调用已订阅的 MCP Server 扩展模型能力，实现工具增强的智能交互。

## 使用前提
使用 HiChat 前，需要完成以下准备工作：

1. 完成开发者账号注册并登录开发者门户。

2. 已创建消费者并设置默认消费者。系统会自动完成默认消费者设置，HiChat 使用该消费者调用模型和 MCP Server。

3. 使用默认消费者完成目标模型产品和 MCP Server 产品的订阅。

## 使用模型
1. 使用开发者账号登录门户。

2. 在导航栏中选择 **HiChat** 进入 AI 交互页面。

3. 在页面左侧的模型选择区域，选择要使用的已订阅模型。

4. 在对话框中输入内容，与模型进行对话。

## 启用 MCP
通过启用 MCP Server，可以为模型对话扩展外部工具调用能力。操作步骤如下：

1. 在 HiChat 页面对话框中，点击 **MCP** 选择器展开 MCP 列表。

2. 从列表中选择要启用的已订阅 MCP Server。

3. 确认该 MCP Server 处于已订阅状态。未订阅的 MCP Server 会显示相应提示。

## 使用联网搜索
联网搜索功能允许模型在对话过程中实时检索互联网信息，增强模型对时效性内容的回答能力。

### 前置配置

使用联网搜索功能前，管理员需要完成以下配置：

1. **配置联网策略**：管理员已在 Model API 所在的网关中配置联网搜索策略。

2. **开启联网参数** ：管理员已在 Model API 类型的产品的模型参数设置中，将 **支持联网搜索** 选项设置为 `true`。

完成上述配置后，已订阅该模型产品的开发者即可在 HiChat 中使用联网搜索功能。

## 订阅管理
API 产品可能配置了消费者认证，HiChat 使用开发者的默认消费者身份进行产品订阅和 API 调用。开发者可以自行指定默认消费者并管理产品订阅状态。

### 设置默认消费者

1. 点击页面右上角的头像展开菜单，选择进入 **消费者管理**。

2. 在消费者列表中找到要设为默认消费者的消费者。

3. 点击该消费者操作列中的 **设为主消费者** 按钮。

4. 在弹出的确认对话框中点击确认，完成主消费者设置。
