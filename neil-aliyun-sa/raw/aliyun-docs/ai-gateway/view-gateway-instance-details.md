本文介绍如何在AI网关控制台查看AI网关实例的基本信息、运行信息和网络信息。  

## 查看网关实例详情
1. 登录[AI网关控制台](https://apigw.console.aliyun.com/#/cn-hangzhou/ai-gateway)。

2. 在左侧导航栏，选择**实例**，并在顶部菜单栏选择地域。

3. 在**实例** 页面，单击目标**实例ID**。

4. 在左侧导航栏单击**概览** ，然后单击**基本信息**页签。

5. 可查看以下信息：

   * 在**基本信息** 区域，查看**实例ID** 、**实例名称** 和**实例类型**等基本信息。

   * 在**运行信息** 区域，查看实例**运行状态** 、**实例规格** 和**接入点**等运行信息。

   * 在**网络信息** 区域，查看**端口** 、**VPC** 和**安全组**等网络信息。

   可以在**基本信息** 页签修改**实例名称** 、管理端口、修改标签、**重启网关** 和**开启WAF防护**。  
   **说明**

   Serverless版AI网关不支持开启WAF防护。
