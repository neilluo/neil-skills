MCP Tool组装功能支持用户通过虚拟MCP服务，在同一个虚拟MCP服务中添加来自多个MCP服务的工具，实现统一的MCP服务入口，避免分散管理多个MCP Server的复杂性。  

## **操作步骤**
1. 在AI 网关控制台的[实例](https://apigw.console.aliyun.com/#/cn-hangzhou/ai-gateway)页面，在顶部菜单栏选择目标实例所在地域。

2. 在**实例**页面，单击目标网关实例ID。

3. 在左侧导航栏单击**MCP 管理** ，在右侧页签中，选择**虚拟MCP服务**。

4. 单击目标虚拟MCP服务，单击**编辑** ，然后单击**添加工具**。

5. 在添加工具页签，选择MCP服务，然后选择所需工具，选择完成后单击**添加**。
