## 智能体构建和治理平台 AgentCore 服务等级协议

版本生效日期：2026-09-18

本服务等级协议（Service Level Agreement，以下简称 "SLA"）约定了阿里云向客户提供的智能体构建和治理平台 AgentCore（简称“AgentCore”）服务可用性等级指标及赔偿方案。

特别提示： 除非另有约定，本协议不适用于 AgentCore 公测、邀测、免费的功能及版本，也不适用于 AgentCore 本地云版本。

## 1. 定义

### 1.1 服务周期

一个服务周期为一个自然月。不满一个自然月的按一个自然月计算。

### 1.2 workspace

workspace 是 AgentCore 的服务单元和逻辑隔离边界，承载 Agent 资产与 Agent 运行时，workspace之间彼此隔离。

### 1.3 失败请求

1. 因 AgentCore Agent 运行时系统原因导致的接口返回状态码为 5XX 和 4XX 的请求；

2. 因 AgentCore Agent 运行时故障导致正常请求未能到达 AgentCore 服务器端的请求（通过故障前 7 天内使用 AgentCore 接口的平均请求数计算）。

### 1.4 有效的总请求

客户某一阿里云账号下，某一 AgentCore workspace 下 AgentCore 服务器端接收到的所有请求视为有效的总请求。

### 1.5 每5分钟错误率

以每 5 分钟为单位按照如下方式计算：

每5分钟错误率 = 每5分钟失败请求数 / 每5分钟有效的总请求数 × 100%

### 1.6 月度服务费用

按一个自然月中客户某一阿里云账号下，未达标服务单元（Workspace）所产生的 AgentCore 服务费用计算（按出账金额计，不含以代金券、优惠券及赠送额度抵扣的部分）。

## 2. 服务可用性

### 2.1 服务可用性计算公式

服务可用性 = (1 − 服务周期内每5分钟错误率之和 / 服务周期内5分钟总个数) × 100%

服务周期内 5 分钟总个数 = 12 × 24 × 该月天数。

### 2.2 服务可用性承诺

Agent 运行时服务可用性不低于 99.9%。

本承诺仅针对 AgentCore 平台自身的 Agent 运行时服务。AgentCore 纳管的第三方 Agent 或客户自建 Agent，其自身可用性、稳定性及服务质量不在本协议保障范围内。

### 2.3 除外情形

赔偿范围不包括以下原因所导致的失败请求或服务不可用以及因此导致的其他损失（包括数据丢失、数据删除、数据泄露、业务中断、资损等）：

(1) 阿里云预先通知客户后进行系统维护所引起的，包括割接、维修、升级和模拟故障演练；

(2) 任何阿里云所属设备以外的网络、设备故障或配置调整引起的；

(3) 客户的应用程序或数据信息受到黑客攻击而引起的；

(4) 客户维护不当或保密不当致使数据、口令、密码等丢失或泄露所引起的；

(5) 客户的疏忽或由客户授权的操作所引起的；

(6) 客户未遵循阿里云产品使用文档或使用建议引起的；

(7) 经客户授权的人工智能服务（包括AI助手、Agent等），在客户授权范围内代为执行实例启停、文件删除等不可逆的操作变更引起的；

(8) 不可抗力引起的。

## 3. 赔偿方案

### 3.1 赔偿标准

以未达标服务单元（Workspace）的月度服务费用为基数，按当月服务可用性落入的档位计算赔偿：

| 月度服务可用性 | 赔偿比例（月度服务费用 ×） |
| --- | --- |
| ≥ 99.0% 且 < 99.9% | 15% |
| ≥ 95.0% 且 < 99.0% | 30% |
| < 95.0% | 100% |

赔偿上限：单一服务单元（Workspace）单月累计赔偿不超过该服务单元当月月度服务费用的 100%；不同服务单元分别计算、可叠加。赔偿以服务代金券形式发放，仅可抵扣 AgentCore 后续账单，不可提现、转让或折现。

### 3.2 赔偿申请时限

客户可以在每月第五（5）个工作日后，对上个月没有达到服务可用性承诺的服务单元（Workspace）提出赔偿申请。赔偿申请必须限于在服务单元（Workspace）未达到服务可用性承诺的相关月份结束后两（2）个月内提出。超出申请时限的赔偿申请将不被受理。
