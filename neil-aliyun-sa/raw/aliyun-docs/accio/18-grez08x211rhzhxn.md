## **常见问题（FAQ）**
#### **Q1：Accio Work 「生意助手智能体」和国际站自带的生意助手有什么区别？**
**A：** 国际站自带的生意助手是一个AI专业工具，有点像“Copilot（辅助驾驶）”，你可以在操作国际站店铺的时候，用它来辅助你一键开店、优化商详、创意生图、全店质检和风险防护等。而Accio Work 「国际站生意助手智能体」则是一个可以根据你的指令自主规划、拆解目标和任务、最终交付结果的Agent，有点像“自动驾驶”，「生意助手智能体」既能调用生意助手的各种功能去操作国际站店铺，灵活交付各种分析报告、诊断建议，一个素材包直接发品/做图/建站……更能配合Accio Work本身的生态（如联动Gmail、LinkedIn等外部）和大模型能力（可切换各种大模型），可以组合出更多强大的玩法且可持续扩展能力边界。它的极限在哪里，取决于你对生意的想象力！

#### **Q2：****使用生意助手智能体和插件如何消耗i豆和积分？消耗明细如何查看****？**
A：两种选择，1）默认优先消耗i豆，i豆不足时消耗积分；2）也可设置仅消耗积分。

:::warning
**选择1：优先消耗i豆，i豆不足时消耗积分**

+ **生意助手智能体内：**所有任务均优先扣生意助手i豆，i豆不足扣 Accio Work 积分
+ **非生意助手智能体：**当调用到生意助手能力时的任务优先扣生意助手i豆，i豆不足扣 Accio Work 积分；其他未调用到生意助手能力的任务扣 Accio Work 积分

**选择2：仅消耗积分**

Accio Work中所有任务均只消耗积分

:::

Accio Work「生意助手智能体&插件」各能力具体i豆和积分消耗，会因用户在 Accio Work选择的模型或任务复杂度不同动态消耗。i豆消耗明细商家在「MyAlibaba后台-生意助手-使用明细」里可以查看，积分消耗在Accio Work端内的用量记录查看。

#### **Q3：如何修改i豆或积分的消耗偏好设置？****<font style="background-color:#FBDE28;"></font>**
A：前往「MyAlibaba后台-生意助手-购买记录」里可以修改消耗偏好设置。默认使用i豆优先，即使用 Accio Work 时优先消耗i豆，i豆不足时再消耗 Accio Work 积分。注意：仅主账号支持修改偏好设置，子账号不支持修改。

![](https://cdn.nlark.com/yuque/0/2026/png/28328816/1782958806295-c1f65d5a-33e1-4f69-80f1-0bbe43c955b4.png)

#### **Q4：使用Accio Work组建团队，团队的i豆和积分消耗是怎样的？**
A：目前在Accio work里可以组建团队，如果团队里包含了生意助手智能体和非生意助手智能体，则会按照用户选择的消耗偏好来决定怎么扣费。

+ **选择使用i豆优先：**由发起指令后处理任务的对象来决定怎么扣费，生意助手处理的任务优先扣i豆，i豆不足扣积分；其他智能体处理的任务中如果调用到生意助手能力会优先扣i豆，i豆不足扣积分，未调用到生意助手能力时依旧扣积分。
+ **选择仅使用积分：**所有任务均只消耗积分

#### **Q5：为什么在智能体对话页面没有看到生意助手插件勾选按钮？**
A：Accio Work 版本需更新至0.12.0及以上。

#### **Q6：我已经是国际站商家且已购生意助手，要使用accio work的生意助手智能体，还需要额外付款吗？**
A：不需要，已经是国际站CGS商家且已购生意助手订单，不需要额外付费，直接通过Accio work Free版就可以唤起国际站生意助手智能体。

#### **Q7：Accio Work中生意助手智能体的入口在哪里，需要复杂的配置吗？**
**A：开箱即用！**用户在Accio work工作台左侧「插件」中选择「国际站生意助手」并授权国际站店铺，授权后自动同步国际站数据和权限（按主-子账号维度）。安装后在左侧「智能体」板块会自动出现「国际站生意助手智能体」，即可开启对话。普通新建智能体需要4步走：给它配上身份-工具-技能-核心文件。「国际站生意助手智能体」完全不需要，已经内置了20+个为国际站商家量身打造的专业技能。

**A：不会！**「生意助手智能体」的对话框下，预置了几大核心场景以及每个场景下的提示词。商家点击提示词，即进入对话框，触发相应技能，支持自己调整。新手商家友好，高阶玩家可以自由提问。

#### **Q10：技能（Skill）是什么？生意助手智能体是不是只能做Skill规定好的任务？**
**A：不会！智能体可以相当灵活。**大模型是大脑，负责理解和思考；Agent 是大脑加上手脚，能实际干活；Skill 是 Agent 掌握的一项项具体技能，每个 Skill 教会 Agent 怎么把某一件事做好。比如「店铺经营分析」这个skill，内化了外贸运营专家要如何分析店铺，要看从曝光开始的流量漏斗、要看商品结构是否健康、要看业务员的跟进态度（时效）和专业度等等，这个skill沉淀了看店铺的最佳范式。当然，因为skill不是workflow（固定的1-2-3-4步），生意助手智能体配置的底层数据源+大模型聪明的理解能力，你自由发问某一个数据、定制自己想要的报告格式/分析维度、甚至让他定时汇报，都是可以的！

#### **Q11：商家需要了解每一个Skill吗？需要手动触发它吗？**
**A：不需要！**每一个Skill都有一个大模型可以看懂的说明书，内置了可以触发它的query。大模型会通过语义理解和当前任务的拆解，做Skill的自主调用、甚至组合使用。当指令不明确或者Skill有重叠，「生意助手智能体」会列出最符合的Skill让商家确认。如果商家已经很熟悉这些skill，比如想要做买家聊天内容分析，也可以直接/唤起技能，避免大模型都试一试，更省Token。

#### **Q12：对比其他普通智能体执行市场调研、店铺分析等任务，使用「生意助手智能体」或调用「生意助手插件」的优势在哪里？**
A：普通智能体是通过浏览器搜索、浏览、爬取页面，来做数据收集。但是这种方式并不稳定，数据也未必准，同时更耗token。本次的「生意助手智能体&插件」直连了国际站数据源和主流C端平台数据API，告别网页爬取，数据更精准，速度更快、更省token。

#### **Q13：Accio Work的生意助手智能体会有操作风险吗？**
**A：不会有操作风险**。生意助手智能体中的市场洞察选品从各个维度推荐商品时，会提示关注侵权和合规风险。智能发品支持「URL发品」、「图+文本描述发品」、「图+文件发品」这三种方式，其中URL发品满足商家在国际站后台自己设置的要求（比如质量分4.2分以上）可以直接发布上线；「图+文本描述发品」、「图+文件发品」属于素材包发品，在Accio Work发品后，实际是进入国际站发品的草稿箱，商家确认后正式发布。即老能力直接发布上线，新能力保持审慎态度需要商家确认。

#### **Q14：使用Accio Work有操作问题、或产品建议，怎么办？**
**A：**最快最直接：问智能体本人！内置了答疑的子Agent，是什么、怎么操作，这类问题你都可以问它。比如Skill是什么？你有哪些Skill？你支持哪些平台搬品？它是一个耐心且专业的好向导！

**遇到报错或者想给我们建议：任务执行结束后，点击「踩」的按钮标识，点它！专人专线快速处理。**
