## **五、常见问题（FAQ）**
#### **<font style="color:rgb(17, 24, 39);">Q：</font>****每个 Agent 都有独立记忆吗****？**
:::tips
+ 每个 Agent 拥有独立的记忆空间，不同 Agent 之间的记忆互相隔离
+ Agent 会在使用过程中自动积累记忆、了解你的偏好并调整行为
+ 删除聊天会清除该次会话的上下文，但 Agent 的长期记忆可能仍会保留关键信息

:::

#### **Q：****拆分多个 Agent 还是用一个？**
:::tips
推荐将不同职责拆分为多个 Agent，而不是全部塞进一个。

原因：

+ 职责清晰的 Agent 调用技能更精准
+ 积分消耗主要取决于模型调用次数和任务复杂度，不是 Agent 数量
+ 杂任务全塞进一个大 Agent 反而容易调错技能

**建议拆分方式（以电商为例）**

选品 Agent、发品 Agent、采购 Agent、优化 Agent 各自独立

:::

#### **Q：****Agent可以安装技能扩展能力吗？**
:::tips
Agent 可以安装技能来扩展能力，类似手机安装 App：

+ 从技能市场搜索并安装所需技能
+ 一个 Agent 可以同时使用多个技能，系统会根据任务自动选择合适的技能组合
+ 你也可以创建自己的私有技能

提示：安装技能后如果没被使用，请确认该技能在 Skills 页面中是「Enabled」状态，同时在当前 Agent 的配置中也被设置为「Selected」。

:::

#### **Q：删除 Agent 后会发生什么？**
:::tips
+ Agent 的私有空间（记忆、配置等）会被清除
+ Agent 会从所属团队中移除
+ 历史对话记录会被保留

:::

#### **Q：为什么在创建智能体时已选择了默认使用的模型，但在用量记录中查看执行任务时切换了其他模型？**
:::tips
设置的“默认模型”负责对话理解和任务调度，但在实际执行过程中，系统会根据任务类型自动调用最合适的模型。当部分任务超出了通用对话模型的能力范围，例如生成图片时，文本模型（如 DeepSeek）无法完成图片处理，为保证输出效果，系统会自动调用专门的图像生成模型来执行。

:::
