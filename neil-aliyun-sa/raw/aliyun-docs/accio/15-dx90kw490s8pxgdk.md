## **一、概述**
可以将 Accio Work 接入常用的办公或社交软件，实现移动端操控和团队协同

## **二、核心作用**
+ 移动办公：在手机上通过微信或钉钉直接向 Agent 下达指令或接收任务完成通知。
+ 群聊协作：可以将 Agent 加入工作群组，通过 `@` 方式召唤，让它成为团队的一员参与讨论。

## **三、支持的平台**
目前已支持钉钉、微信、飞书、企业微信，其他平台正在陆续打通中

## **四、常见问题（FAQ）**
#### **<font style="color:rgb(17, 24, 39);">Q：</font>****<font style="color:rgb(17, 24, 39);">如何连接 Telegram 机器人？</font>**
:::tips
1. 在 Telegram 中找到 `@BotFather`，创建机器人并获取 API Token
2. 在 Accio Work 中进入「Channels」
3. 找到 Telegram 卡片并点击「Configure」
4. 粘贴 API Token
5. 点击「Start」，状态显示「Online」后即可使用

:::
