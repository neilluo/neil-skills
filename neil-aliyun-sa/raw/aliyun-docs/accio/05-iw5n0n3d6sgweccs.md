## 一、免费额度怎么算
+ 每个账号每 24 小时有 **20 个每日积分**。
+ 从**首次使用**开始计时。
+ 额度用完后，**24 小时自动补充**。
+ 未用完的额度**不会累积**到下一周期。

新用户另有 **7 天体验期**，期间可获得额外的奖励积分和高质量模型访问权限。

## 二、订阅积分
订阅积分是付费套餐专属积分，与每日积分使用同一套积分系统，在免费额度之上提供更多每月可用积分。

## 三、积分是怎么消耗的
不同模型消耗不同积分，影响消耗速度的因素：

+ **模型选择**。极致模型功能强但消耗快，`**<font style="background-color:rgba(15, 23, 42, 0.06);">Auto</font>**` 模型更经济。
+ **任务复杂度**。任务越复杂、上下文越长，消耗越快。
+ **工具调用**。调用的工具越多，消耗越快。
+ **并行任务**。多任务并行时更容易快速消耗当天额度。

## 四、高质量模型限额
高质量模型按订阅档位在**每 3 小时滚动窗口**内有调用上限，避免少数高频会话占用过多共享资源。

| **套餐** | **高质量模型上限** |
| :--- | :--- |
| Free | 不可用 |
| Pro | 50 次 / 3 小时 |
| Elite | 150 次 / 3 小时 |
| Ultra | 无限制使用高质量模型 |


## 五、Auto 模式
`**<font style="background-color:rgba(15, 23, 42, 0.06);">Auto</font>**` 与其他模型使用**同一套积分系统**。它会为任务自动选择更合适的模型，让简单任务保持高效，复杂任务也能获得更强支持。

## 六、限流与额度问题排查
出现 **“限流”** 或 **“模型访问受限”** 提示时，先区分两种情况：

| **情况** | **含义** | **处理方法** |
| :--- | :--- | :--- |
| 当天额度已用完 | 本周期积分用尽 | 等 24 小时刷新，或升级套餐 |
| 模型侧负载高（额度还有但仍受限） | 该模型临时容量不足 | 切换到其他模型重试 |


**建议处理顺序：**

1. 先看左下角**额度指示**是否已用完。
2. 没用完就**换模型**。
3. 换模型仍失败就**稍后重试**。

## 七、其他常见问题
| **问题** | **解答** |
| :--- | :--- |
| 额度明细和消耗账单能看吗？ | 系统持续优化额度展示能力，后续将提供更详细的消耗账单。 |
| Accio 网页版和 Accio Work 的积分互通吗？ | 网页版和客户端的积分互通。管理订阅需要跳转到**网页版**升级或降级。 |
| 绑定微信 / 钉钉会额外消耗积分吗？ | 不会。绑定微信或钉钉不影响积分消耗。积分消耗只和模型调用次数、任务复杂度有关。 |
