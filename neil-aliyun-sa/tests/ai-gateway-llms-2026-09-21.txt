# AI 网关

> AI 网关是云原生 API 网关面向 AI 原生应用的托管入口，统一代理百炼/OpenAI/MiniMax/Anthropic/Amazon Bedrock/Azure 及 Ollama/vLLM/SGLang 自建模型，兼容 OpenAI 协议；支持 Model API/Agent API/MCP Server 三类接入，覆盖多模型路由、按比例灰度、HTTP to MCP 转换、A2A 协议转换、消费者 API-Key/JWT/HMAC 鉴权、KMS 凭证托管、Token 限流、Fallback、语义缓存、AI 安全护栏（内容合规/提示词攻击/敏感数据/恶意文件/水印）与全链路可观测；提供专享实例与 Serverless 实例，按实例规格或 AI Credits 计费。

本文档内容仅适用于「阿里云中国站」，阿里云国际站文档请参考 https://www.alibabacloud.com/help/llms.txt
