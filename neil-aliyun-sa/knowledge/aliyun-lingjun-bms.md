## 1. 定位与产品边界

**智能计算灵骏（裸金属形态）= IaaS 层 GPU 裸金属集群**，用户拿到 root SSH 的物理机；PAI 灵骏是 PaaS 平台（DSW/DLC/EAS），拿不到节点。两者共用同一批物理机与同一套内部卡型代号，但**是两个独立商品、两套命名、两套价格**：

| 维度 | 灵骏裸金属 | PAI 灵骏智算资源 |
| --- | --- | --- |
| 商品 code | `bccluster_eflocomputing_public_cn` / `_intl` | PAI 侧商品 |
| 规格命名 | 模块值 `efg1.* / efg2.* / efg3.*`（⚠️ **例外：L20P 为 `efg.GN9P.n8`，无版本号，程序化解析须容错**），机型 `gu7ef / gu8xf / gs8xf / gn9c.cn8 / p16en` | `ml.{gu\|gx\|gp\|ga}{7\|8\|9}{字母}f.{卡数}.{CPU规格}` |
| 计费模块 | `module_code=computingserver`，`module_name=节点型号`，`价格类型=monthPrice`，单位 **元/台**（国际站 美元/台） | 按月 / 按量（元/分钟） |
| 交付物 | 物理机（root 密码 SSH）+ 集群 + RDMA 高网 | DSW/DLC/EAS 任务 |
| 控制台 | `lingjun.console.aliyun.com` | PAI 控制台 |

**灵骏连接**（`bccluster_cloudconnectionpre_public_cn`，预付费）：列表价默认 **1G 带宽 5,000 元/月**，可按日提升/降低带宽。**A100/A800 系统盘走本地 SATA 盘，不需单独买云盘，但必须单独配置「灵骏连接」打通 VPC**——可以理解为 CEN 专线的一种产品形态。[官方内部]

> 🔴 **金融云那 0.80 的成因（重要，别误判成"两套定价口径"）**：PAI 上海金融云 PPU810E 的 ¥280,006.8 **恰好是裸金属 2026-04-18 涨价前的目录价 ¥280,007**——本质是**PAI 侧没跟涨**，不是稳定存在的口径差。这个 0.80 会随 PAI 侧调价而消失，**不可作为长期报价依据**。

**衍生结论**：PAI 灵骏**按量单价（元/分钟）× 43,800 分钟（730h）≈ 包月价 × 1.5208**——A800/H800/L20C/L20D/L20A/L20B 六组实测比值集中在 **1.520822~1.520844**（离散度 ±0.00001）。即按量比包月贵约 **52%**，不是常见的 2–3 倍。[推断]

## 4. 固费分期折扣阶梯（内部报价必备）

列表价表给六列：**月单价 / 半年月价 / 一年月价 / 两年月价 / 三年月价 / 四年月价**（均为「月」价，整购分期）。

🔴 **第一条红线：半年档与两年档是按 SKU 行开放的，不是按卡型。** 列表价表 97 个有价 SKU 里**只有 23 个**填了半年与两年价（这两列同现同缺，集合完全一致），其余 74 个只有「月 / 一年 / 三年 / 四年」四档。**同卡同地域都会不一致**——L20X 上海 B3 有全六档，而上海 B4 / B6 / C1、上海 N2 只有四档；PPU810E 乌兰 C3 有六档，而乌兰 A、D1、D2 只有四档。**报期限前必须回列表价表查那一行**，不能按卡型推。从未出现过半年/两年价的卡型：`H100`、`H20-96G`、`H20-141G`、`L20A`、`L20B`、`L20C`、`L20D`、`L20P`、`PPU810`。

- **新加坡 `gu8ef` 系（H100 / L20Z）折扣最深**——一年 0.6242、四年 0.3483，明显优于其他卡型；但该 SKU 的三个档位反推出的基数互不相等（详见 § 12），报价前要回源核对。

**涨价清单侧的档位分布**：`无优惠` 60 行 / `6个月整购优惠` 12 / `12个月整购优惠` 61 / `24个月整购优惠` 12 / `36个月整购优惠` 60 / `48个月整购优惠` 61。6 个月与 24 个月两档各 12 行，卡型构成为 **PPU810E 6 行 + H800 5 行 + H20-96G 1 行（河源蚂蚁）**——这 1 行 H20-96G 正好反证「半年/两年档是 SKU 粒度而非卡型粒度」，**不能说"H20 全局没有半年/两年档"**。

## 10. 开通流程（内部实操，裸金属单租形态）

**入口**：控制台搜「智能计算灵骏」，或 `https://lingjun.console.aliyun.com`。⚠️ 文档里「国际站 UID」给的链接域名仍是 `lingjun.console.aliyun.com`，只有 `spm` 参数不同——**不是独立的国际站域名**。进入后先确认地域（示例用「华北6（乌兰察布）」）。

**① 购买节点**：节点管理 → 购买新节点 → 选集群编号（示例 C1）→ 选卡机型 → 选节点数 → 提交。**看不到目标机型 = 账号没走加白流程，找灵骏 PDSA**。购买成功后在节点管理列表可见，状态为「未使用」。

**② 创建集群**：集群管理 → 创建集群 → 选**「基础灵骏集群服务（裸金属形态）」**。
- **第一步 创建 0 节点集群和分组**：填集群名称、集群编号、**登录密码（这就是后续 SSH 登录物理机的 root 密码）**；创建分组时选默认机型、镜像、节点名前缀。可以先建 0 节点集群，之后再扩容。
- **第二步 网络配置**：选 VPC / vSwitch / 安全组。⚠️ **这一步的 vSwitch 是「灵骏物理机 vsw」——GPU 服务器物理网络占用的交换机，属控制面网络，一台机器占一个 IP**，容量规划要按节点数预留 IP。POC 场景建议新建独立 VPC + 默认安全组。CPFS 可选挂载，**纯推理场景通常不需要**；如要买 CPFS 需联系存储 PDSA 报备加白，购买页会跳到独立下单流程，买完手动填挂载路径。
- 🔴 **确认配置这一步，ARMS 必须已开通 Prometheus 服务才能通过**——没开就卡在最后一步，是高频卡点。
- **第三步 扩容节点**：把「未使用」节点加入集群，节点状态变「扩容中」，进度在任务中心看。
- **正常节点的 IP 语义**：**第一个私网 IP = 入 VPC 的 ENI 私网 IP，其余 IP 是自动分配的高网 IP（RDMA 互联用）**。排查网络时不要把高网 IP 当业务 IP。

**③ 节点使用与登录**：灵骏控制台支持**带内 / 带外**两种登录，也可用同 VPC 内的 ECS 作跳板机。

**④ 公网访问**：配置**公网 NAT 网关**（源文档写作「NET 网关」，是笔误）做 SNAT 出网 / DNAT 入网，**NAT 网关必须绑定 EIP**。⚠️ **配了 DNAT 之后还要在安全组放行 22 端口**，VPC 外才能通过 EIP 访问 GPU 节点。这条与知识库已有结论闭环：**灵骏节点与 PAI 各模块都不能直接绑 EIP，公网统一走用户 VPC 的 NAT 网关**。

**⑤ 🔴 本地 NVMe 挂载必须加 `nofail`**：实例本地 NVMe 盘如果格式化挂载使用，**故障后会默认走备机替换（不是修机）**；原云盘 OS 无法识别备机的本地 NVMe uuid，**因此 fstab 挂载项必须加 `nofail` 参数，否则替换流程会失败**（与 ECS 实例规则一致）。推论：**盘上数据不跟随备机，模型/checkpoint 必须在 OSS 或 CPFS 另存副本**。

## 11. 退订流程（不能自助）

集群管理里对目标节点执行**缩容** → 节点状态变「未使用」→ **提工单**（产品分类选「智能计算灵骏」）→ 在线服务中按售后工程师提示提供**退订的实例 ID** → 确认节点状态与订单信息 → 售后给出退订链接 → 选退订原因 → 点退订 → **等后台回收机器后关单**。

🔴 **两条对客口径**：①**必须先缩容再退订**——原文只写「缩容节点后，节点状态变成未使用，即可进行提工单退订」，"未摘除就退不了"是由此推出的 [推断]；②**退订走工单人工流程**，原文全程是"提工单 → 售后给退订链接"，**未见任何控制台自助退订入口**（"无自助入口"同为 [推断]）。因此「按需上下线」的弹性叙事在灵骏裸金属上不成立——要弹性得看 PAI 灵骏 Serverless（其 SLA 与计费模型见 § 14.6）或 ACS/EAS。这条在给客户设计「先小规模 POC 再决定是否退」的方案时必须提前说清预期时长。

## 13. SA 报价与选型速查（结论层）

1. **先问地域再问卡**。同一张 H20-141G，乌兰察布 ¥194,713 到迪拜 ¥374,469，差 1.92 倍；金融云/政务云再叠 1.9–2.0 倍（但成都蚂蚁反而是 0.89× 折价，蚂蚁专属可用区必须逐个取价）。地域没定就给不出有意义的数字。
2. **报价单位是「元/台·月」，不是「元/卡·月」**。8 卡机与 16 卡 PPU 机、72 卡超节点的「台」含义完全不同，PPU810E ¥184,215 是 16 卡的价，折到单卡是 ¥11,513，比 H20-141G 的单卡 ¥24,339 便宜一半以上——**PPU 的性价比叙事要建立在单卡口径上**。
3. **锁期折扣有四套阶梯，不能只记一套**：标准 0.75/0.50/0.388、H20 系与 L20P 0.7366/0.4998/**0.4409**、超节点 0.7547/0.50/0.3868、新加坡 `gu8ef` 系 0.6242/0.4469/0.3483。🔴 **半年档与两年档是按 SKU 行开放的**（97 个在售 SKU 只有 23 个有），**同卡同地域都可能不一致，报期限前必须查那一行**。详见 § 4。
4. **裸金属 ↔ PAI 用 ×1.10 换算**（17 组实测 1.099996~1.100003）。三类例外：PPU810E 京沪杭为 1.000、新加坡 `gu8ef` 系要看 SKU 后缀（`-ha4` 精确成立、非 ha4 为 0.92）、少数 `ncp` 标注行反推不到。客户在「自己运维裸金属」和「用 PAI 托管」之间比价时，**PaaS 溢价只有 10%**，这个数字比多数人预期低得多，是推 PAI 的有力论据。
5. **PAI 按量 ≈ 包月 × 1.5208**（730h 折算，六组实测离散度 ±0.00001），不是 2–3 倍——短周期 POC 走按量的经济性比直觉好。
6. **<8 卡不要报灵骏**（价格单位 266 行全为「元/台」，最小交付单位是整台 8 卡机 / 16 卡 PPU 机 / 72 卡机架）[推断]，小规模推理走 EAS 独享或 ACS GPU。与 § 14.7 第 1 条同源。
7. **H20-3e（141GB）vs H200（L20X）**：显存同为 141GB，乌兰 H20-3e ¥194,713 vs 上海 L20X ¥456,930，**推理场景优先 H20-3e**；但注意两者不同地域，同地域（上海）对比是 ¥208,039 vs ¥456,930，仍省 54%。
8. **超节点只能开海外**，国内客户要 72 卡机架级方案，现阶段只能落新加坡/泰国/柔佛，**数据出境合规必须前置评估**。
9. **两条工程红线写进方案**：本地 NVMe 挂载加 `nofail` + 模型在 OSS 留副本；系统盘按量欠费会停整台机。
10. **退订是工单人工流程**，不要向客户承诺「随时可退」。
11. 🔴 **勘误（2026-08-11 修正）**：此前"灵骏裸金属**无公开 SLA**"的结论**有误**。《智能计算灵骏服务等级协议》确实存在且公开挂在 terms.alicdn.com（生效 2023-12-10），只是**不含任何可用率百分比**，补救措施是"客户报修确认故障后，可退订该节点并停止计费"——与 ECS 单实例 99.975% + 按可用率赔代金券的模型完全不同。详见 § 14.6。

## 14. 灵骏 vs ECS 裸金属：本质区别与选型判据

> ✅ **本节例外：全部为 help.aliyun.com / terms.alicdn.com 公开文档，可对客**（与本页其余 §1–§13 的内部口径不同，引用时不要跨节混用）。
> ⚠️ 阿里云**没有任何一篇 ECS vs 灵骏 的官方选型对比文档**（已逐页核验灵骏简介、GPU 规格族页、SCC 三篇、E-HPC、部署集，"灵骏"在 GPU 规格族页出现 0 次），故 § 14.7 的选型判据须标注为**架构建议**而非官方结论。

### 14.1 一句话

**ECS 裸金属交付「云上的一台机器」，灵骏交付「云上的一片集群」。** 差异不在单机性能（sccgn7ex 的 800Gbps RoCE + NVSwitch 并不弱），而在**集群规模上限、网络对象模型、故障处置方式与商务形态**四件事上。

### 14.3 网络：最本质的一处分岔

- **方向相反**：ECS 是"在 VPC 里加速"（eRDMA 复用 VPC，自研 CC 算法容忍丢包，官方原文明说传统 RDMA"依赖网络无损特性，规模部署困难"）；灵骏是"先建一张独立 AI 专网，再反向接回 VPC"。
- **硬约束**：「如果节点之间需要进行 RDMA 通信，这些节点**必须部署在同一个灵骏网段内**，因为 RDMA 不支持跨灵骏网段通信」；「一个灵骏集群只能部署在一个灵骏网段内」→ 网段 CIDR 规划直接决定集群可扩到多少节点（官方建议掩码 <22，子网掩码不小于 23，同节点多张网卡分接不同子网以免 ARP 条目过多导致 **RDMA 抖动甚至训练中断**）。
- **多平面**：官方用"参数面"一词——「NCD 树图仅展示用于**参数面通信**的网卡，即除第一张网卡（或弹性网卡）以外的其它网卡」；并有「**存储流量和计算流量分离**，避免存储流量干扰计算流量造成并行通信抖动」；CPFS 走专门的 **OOB 类型子网**。
- **代价**：灵骏放弃了安全组/EIP/SLB 这些 VPC 原生治理能力，换来参数面确定性。访问控制手段只有"网段隔离 + 灵骏HUB 路由策略（≤100 条）+ 跨账号授权"三件套，**没有五元组级 ACL**。
- 🔴 **公网访问与 ENI 的演进（重要更新）**：灵骏文档全站无 EIP/NAT 字样，官方给出的 SSH 路径是"控制台远程登录 / 同 VPC 的 ECS 跳板机 / 公网 NAT 网关 DNAT 端口映射"。但《管理灵骏弹性网卡》已置顶写明：「**如果您新购灵骏计算资源，目前除下述实例外，其他灵骏实例均可使用阿里云标准弹性网卡（ENI）**……存量资源可联系客户经理升级」——即新机型挂上标准 ENI 后，理论上可用 EIP/NAT/SLB 等标准 VPC 能力，但**官方无任何一页明文写"灵骏可绑 EIP"，不得对客承诺**，落地前须与产品/客户经理确认。仍必须用 LENI 的实例：乌兰察布 A1(`efg2.nvga8n`/`efg2.nvga1n`)、A2(`efg2.nvgh8bn`)、B1(`efg2.nvga1`/`efg2.nvga4`)、河源 C1、新加坡 A1。

### 14.4 存储：CPFS 智算版是官方划死的分界线

《CPFS 智算版使用限制》原文：挂载方仅支持「灵骏智算资源、PAI 通用计算资源、PAI 灵骏智算资源（单租户版）、ACS 高性能网络 GPU 型」，**明确"不支持 ECS 实例直接挂载"**；走自研 **VSC 虚拟存储通道 + RoCE RDMA**，仅 POSIX，单文件系统 VSC 挂载 **4000 节点**、**最多 1 个 VPC 挂载点**。→ 客户要"训练存储不成为瓶颈"这条，ECS 侧只能退到 NAS/OSS/ESSD 或 CPFS 标准版。

另一条容易过时的旧认知：**灵骏系统盘已从本地盘升级为 ESSD 云盘**（2025-07-15 产品动态），节点扩容"小时级→分钟级、耗时下降超 90%"，并支持快照与基于快照的自定义镜像，单节点云盘挂载数 >48。而 ECS **GPU 裸金属官方规格表里没有"本地存储"列**，只有弹性临时盘 + ESSD——"ECS 有本地 NVMe"是错的。

### 14.5 运维模型：节点是"可替换的无状态算力单元"

灵骏侧三种操作全部清盘：缩容（「被移出集群的节点重装，本地数据全部清空」）、重装、备机替换。加上 SLA 例外条款第 (6) 项"本地盘数据丢失风险不予赔偿"，工程含义只有一个：**状态必须外置到 CPFS/OSS，靠 checkpoint 恢复**。配套的是 PAI 侧 **AIMaster 容错引擎**（Hang 检测默认 1800s、`--max-num-of-job-restart` 默认 3、Error 级日志自动隔离节点并重拉任务）与**灵骏专属 C4D**（慢节点/Hang 节点定位，依赖自研 ACCL，`C4D_HANG_TIMES` 默认 18 次≈挂起 3 分钟触发自动隔离）。ECS 侧对应能力则分散在别处：拓扑感知调度属 **ACK**、调度与伸缩属 **E-HPC**，**GPU 故障自愈与训练任务级监控在 ECS 文档中查无此物**。

### 14.7 选型判据（架构建议，非官方文档）

1. **≤8 卡、单机训练或推理、要 VPC 原生治理与自助弹性** → ECS GPU（`gn8v`/`ebmgn8v`，官方语"8 卡之间支持 NVLINK 互联，**适用于中小模型训练场景**"）。与本页 §13 第 6 条"<8 卡不要报灵骏"是同一条线的两端。
2. **十几到百卡、需要独立 RoCE 面** → SCC `sccgn7ex`（800 Gbit/s + NVSwitch + GPUDirect，官方语"适用于**超大规模 AI 训练场景**"）。**但要提前告知客户两条边界**：部署集低时延 ≤20 台/可用区且 scc 不在支持列表、官方无集群规模上限口径。
3. **>100 卡** → 灵骏。这是**唯一带阈值的官方表述**，出自《阿里云具身智能网络白皮书》网络投资决策框架：「触发条件：**训练集群 > 100 GPU 卡** → 部署 eRDMA + HPN 7.0 高性能网络 → 预估投入增量：**含在灵骏集群费用中**」。千卡以上、要拓扑亲和调度 + 故障自愈 + 存算流量分离时，只有灵骏这一条路。
4. **卡型可得性往往先于架构决定结论**：ECS GPU 规格族页全文 **"A100/H100/H800/H20" 出现 0 次**（只写显存/带宽/算力，型号只点名 V100/T4/A10/L20），且 `ebmgn9g` 系邀测、`ebmgn8v` "仅支持海外等部分地域，如有需求请联系销售"。客户点名要 H20-3e / H200 / 72 卡机架时，实际能落的是灵骏侧 SKU。
5. **地域会二次收窄**：灵骏本体 19 个地域，但 **PAI 灵骏智算资源仅 6 个**（乌兰察布/北京/上海/杭州/深圳/新加坡，且白名单）、**CPFS 智算版 15 个 + 华东2金融云（邀测）**。中卫、呼和浩特、张家口、亚特兰大这 4 个灵骏地域，PAI 与 CPFS 智算版都不覆盖。
6. **采购流程差异要提前暴露**：ECS 是配额审批（配额中心自助提额），灵骏是"销售报备 + 集群编号 + 退订按合同执行"，且**灵骏计算节点配额不进配额中心**（配额中心只管灵骏网络资源，仅乌兰察布/河源两地域）。客户 IT 采购流程如果要求"预算可锁定 + 可自助退订"，灵骏这条要单独说明。
